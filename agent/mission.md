# 项目任务

当前方向（2026-10-02）：面向开发建设企业投资拓展与前期策划人员的老旧小区改造前期研判辅助智能体。首版聚焦老旧小区综合整治提升，辅助决定是否继续投入尽调资源、当前方案有哪些阻断条件、下一步优先核实什么。

首版采用杭州西湖区翠苑一区作为真实公开历史验证案例，不将历史招标、竣工报道或后续加梯记录当作当前可投标项目。项目整体、单栋建筑、社区和周边片区的资料分别记录空间范围与时点。公开案例数量存在来源差异时并列保留，不拼成一个确定值。

业务六维：居民需求、公共服务、居住工程、实施协同、长效维护、资金交付。六维用于组织观察、证据与待核项，不是官方评分标准，也不是可信概率；未知项不按零分处理，硬约束不得被综合分数抵消。

行动输出限于“建议进一步尽调”“先补充关键资料再判断”“当前条件下暂缓”。先检查已核实且足以独立否决当前方案的条件，再检查关键资料与适用规则，保存每项建议的触发依据。正式指标口径、门槛和适用边界须由企业人员及专业教师复核。

信息沉淀以一项决策经验为单元，所属项目存于 project_id；提取决策问题、背景目标、关键条件、备选方案、提议、实际决策、决策依据、实施、实际结果、适用边界十个字段，并保留每字段原文定位、材料版本与审核状态。提议、实施和结果分别记录；原文没有的历史理由不得由模型补写。

用户可调整基础、完善、提升类改造方案；程序按工程量、单价、已落实出资和运维假设进行静态测算，说明变化及受影响判断。复用现有地图、解析、检索、证据、版本与计算能力，保留 CRE 应用壳和 DSH 唯一运行时，不新增并行调度器。

当前未获得获准使用的企业历史项目样本，不编造企业效果、经验提取准确率或行动判定指标。工程回归、公开材料核对和真实决策质量评价分别报告；评测按项目隔离并限定研判时点。
