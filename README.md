# 海之子 · 建造前片区研判工作台 v0.2

工作台默认从高德 3D 地图进入：浏览街区 → 一键专题标色 → 点选查看地图事实与已有项目证据 → 按需生成初判 → 进入项目研究。已有真实模型主链、企业经验编译、局部重评、历史差异、材料上传、语料整理和报告导出继续使用。

这是本地研发与试点版本。工程测试、真实 API 联调和企业决策效果是不同的验证层次，当前没有声称已验证企业投资收益或替代专业审批。

## 当前电脑直接使用

打开 **http://127.0.0.1:5173**。需要启动时，Windows 双击 `启动工作台.cmd`，或在当前目录的 WSL 终端运行：

```bash
bash scripts/start.sh
```

启动器使用本工作区的 Node 与 Python 环境；重复启动会提示已有服务，避免重复打开数据库。前端 5173、应用宿主 4310、专业能力服务 4311，均监听本机。

本机模型密钥保存在被忽略的 `.env`；新克隆不含任何密钥，需要自行配置。密钥不会打入交付包或放入前端。默认模型配置为 `deepseek-flash`，每次模型调用的实际返回标识、token、耗时和子会话均保留。

## 怎么操作

1. **地图浏览**：滚轮缩放、拖拽平移、右键调整方向与倾角；右下角可切换 2D/3D 和恢复正北。图层菜单可切换城市地图、卫星影像与建筑楼块。
2. **选中先看事实**：右侧直接展示交通、商业、居住办公与文教医体记录，并关联真实项目来源。点“结合资料生成初判”才调用模型；点“查看地点详情”进入地点详情。普通位置不被冒认为已核实建筑。
3. **地图标色和数据目录**：一键固定中心片区的 3×3 范围，按单指标标色；切换专题复用快照，拖图不重跑模型。“项目数据”显示真实项目、来源、覆盖和待补项，排除合成样例。
4. **进入项目**：从地点详情“以此处创建研究项目”，或在左侧“项目”中选中已有项目，再“进入项目研判”。返回地图时保留视角。选点保存为明确的 GCJ-02 点位，不冒充 WGS84 研究边界。
5. **自动初筛**：在项目研究详情右上角选择“真实模型研判”，启动初筛。创建项目本身不会自动消耗模型额度。
6. **查看依据与企业增强**：在资料与证据中查看原文和来源；加入企业经验后，在“版本与变化”查看局部重评的差异。未变化工件复用，旧报告不覆盖。
7. **继续工作**：把调查项加入本地清单，或导出 Markdown 决策报告。失败的运行可以“继续未完成研判”，从原快照和完成工件恢复。

“离线工程验证”是单独的可选模式，不会冒充真实模型调用。真实项目不自动填入合成建筑、收益或企业能力数据。

## 高德地图连接

本机已保存用户提供的高德 Web 端（JS API）配置。更换时打开左侧“设置”，填写 JS API Key 与配套 `securityJsCode`；也可在 `.env` 中配置 `AMAP_JS_KEY` 和 `AMAP_SECURITY_CODE` 后重启。界面配置位于被 Git 忽略的 `data/local/amap-credentials.json`，优先于环境变量。

高德 JS API Key 按官方方式用于浏览器 SDK；安全密钥只留在本机服务端，经受会话保护的 `/_AMapService` 代理使用，配置接口不会返回它。源码包不包含配置文件。接入依据见 [高德安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。

3D 楼块是地图模型，不是建筑实景重建或室内 VR。高德会对部分软件显卡降级为平面地图；本机已用 Windows Chrome 的硬件 WebGL 验证 3D，界面会如实显示降级状态。真实楼块、影像和地点信息以高德覆盖为准，不替代工程资料。

## 已接入的能力

- **CRE 工作台与 ParserPort**：选择性复用界面结构、通用文本/CSV 解析、PDF/Excel 提取与表格来源定位、报告表格逻辑；没有运行原收购控制器或固定 verdict 演示。
- **DeepSeek Harness**：实际使用 AgentLoop、受限 Subagent、结构化输出、工具注册、JSONL 持久化与父会话恢复。业务角色只能使用获授的分析工具和结构化结果工具。
- **真实研究链**：原生 DeepSeek 搜索、DSH 匿名公开 HTTP 获取、Readability 原文抽取、专业研究、候选生成、独立反证及六维条件比较。
- **数据与数值**：PGlite 嵌入式 PostgreSQL；Shapely/pyproj 范围计算；BM25 检索；HIRE 只读查询接口、RETQA 槽位、GeoAgent 元数据、STORM 信息归并及 Search-o1 摘要模板的有限移植。
- **统一契约**：一份 JSON Schema 生成 TypeScript/Pydantic；跨语言往返、来源引用、合成标记、项目作用域与输出约束均有检查。
- **上下文与恢复**：规则可撤销、可追溯；规范化 JSON 内容哈希避免 PostgreSQL 键顺序改变造成错误失效；已验证阶段先落盘，恢复只补未完成环节。

具体迁移符号、上游 ref/blob、许可证、修改和测试见 `research/upstream.lock.json`。

## 材料与数据边界

支持 TXT、Markdown、CSV、PDF、DOCX、XLSX，单文件 ≤ 10 MB。表格保留行定位，不跨建筑拼接数值，不自动把一张表的合计当成整个研究范围的面积。原始文件与 SHA-256 留在本地。

PDF 文本读取最多前 50 页；Excel 限 30 个工作表、每表读取 5000 行、展示前 250 行；结构化行预览有数量上限。扫描 PDF 无文本时明确提示需要 OCR，不算解析成功，也不拿空文本作证据。

真实内部正文默认不发到外部模型。企业已经允许该端点时，才在本机配置 `ALLOW_INTERNAL_MODEL=true`；否则内部意见使用本地编译、组织边界在本地执行，模型仅使用获准公开信息。显式合成的测试经验可以用于真实模型联调。

地名解析使用可配置的中国公开研究 RegionPack 和 Open-Meteo/GeoNames 地点数据，只用于非商业研发/研究。保留同名歧义；地名代表点不是研究边界、宗地或开发权利。商业部署需按所用数据服务条件另行配置。没有路网数据时不提供路网可达性结果。

## 语料与训练数据整理

已增加本地整理流程：公开来源归集、原文哈希与定位、去重分组、待标注样本、用途记录和训练/开发集导出。第一批整理了 6 条公开来源（5 条有正文）、17 个文本块与待标注候选；10 个合成输入和 8 条模型记录单列为回归材料。模型答案没有自动转成人类标签。

```bash
export PATH="$PWD/.tools/node/bin:$PATH"
npm run corpus:build
npm run corpus:search -- --query "城市更新 实施组织"
npm run corpus:export
```

查看 `data/local/corpus/语料台账.md`；采集、标注格式和后续资料重点见 [语料整理说明](data/corpus/README.md)。生成材料与标签留在本地忽略目录。现有资料已参与开发，尚无经批准的训练样本或独立最终评估集；这一步没有启动权重训练或消耗模型 API 额度。

## 复现环境

本次实测环境：WSL Ubuntu、Node.js 24.21.0、Python 3.14.4。原生 Windows 开发链和外部 PostgreSQL/PostGIS/pgvector 尚未验收；当前默认持久化使用已实测的嵌入式 PostgreSQL。

新环境安装：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
npm ci
cp .env.example .env
npm run dev
```

模型和搜索的配置分别检查；DSH 自身的代理解析负责读取机器已有 HTTP(S) 代理并绕过本机服务。密钥不要填写进前端、源码或 Git。

## 验证与证据

```bash
export PATH="$PWD/.tools/node/bin:$PATH"  # 当前工作区自带 Node 的使用方式
npm run verify                         # 契约、单元、完整 HTTP/SSE 流程、重启与构建
npm run live:smoke                     # 真正调用模型/原生搜索，会使用 API 额度
npm run test:live                      # 显式执行四个真实联调场景，会使用 API 额度
```

`test:e2e` 在临时目录与 14310/14311/15173 端口运行，明确关闭模型凭据，不操作当前项目数据。真实联调证据独立保存在 `research/live_smoke/`；汇总在 `research/test_results/verification.json`。浏览器截图在 `output/playwright/`。

实际已验证的真实场景包括：合成初筛、项目约束更新、杭州公开资料研究、提示注入样例与私有标记隔离。杭州案例取得 4 篇政府网站原文，另 1 条缺正文记录保留为待核。该结果不能解释为真实地块或企业效果已获验证。

原包 `research/local_test_log.txt` 仅是最初 16 项基础检查。完整 CRE 上游原版解析套件的历史失败记录保留，不能与当前迁移后适配器测试混为一谈。

当前地图初筛与真实数据关联说明见 [地图与数据设计](docs/地图初筛与数据关联.md)。本地目前只有杭州公开资料案例和地图事实，没有真实租金、成交、成本和建筑权属数据库，界面不会填入示意图的投资总分或价格趋势。
