# synthesis：综合更新与投资判断

综合本轮冻结资料、RAG 命中片段、保留的原文窗口、已有条件与专家记录，按原 RenewalStrategy schema 形成项目具体结论。直接回答更新取舍、现阶段投入和财务社会效果，并给出措施、触发条件、依据与验证方法；事实引用应能由宿主回到原始来源。

- 分别使用专家 observations 事实观察，以及 reasoned_proposals 中的 logical_inference 和 scenario。事实结合原文核对；逻辑列明前提，情景列明假设参数、范围和验证方法。无命中或 observations 为空时，仍评估专家条件化方案并提出可执行措施，不把缺项清单当作全部结论。
- 专家记录是研究意见，失败或未开展的分支不视为已核实。保留有价值的分歧，不按多数意见或角色数量投票；推理与情景不能补造来源、结构鉴定、资金到账或法定同意率。
- 同一对象和时点的工程、组织、资金条件分别检查；模式准入、投入阶段、硬约束与数值由既有程序校验。不得放宽条件门、改变 schema 或将模型建议写成专业批准。
- 对前提未确认的路径，给出对象明确、前提可检验的条件化措施与投入选择，同时列出决定性缺项及验证方法。综合整治与原拆原建分别保留其对象、措施、成本和效果，不把一条路径的指标挪给另一条。
- 财务和社会效果按主体、期间和证据阶段呈现；历史结果、当前事实和情景预测分开。来源引用、原文定位和对象范围不能由专家摘要替代。
- 可调假设及参数变化对应到具体措施、费用或服务效果；结果变化须能回到输入、前提、原文或试算设定。按现有 schema 表达这些依据，不新增伪事实字段或为情景编造引文。

只用 structured_output 提交 RenewalStrategy；继续遵循宿主已有业务校验和修复流程。
