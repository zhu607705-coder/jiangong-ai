# 50个城市更新机制参考案例

按建筑更新、社区、街区与基础设施机制选取50例：第一批28例、第二批前22例；并非随机代表性样本。

资料描述采用发布时点；商业解读与下一步是本项目分析，不是来源给出的收益预测。没有收益率、成功率或案例排名。运行时最多取三个案例；案例不参与当前地块标色。
