# PR2：公开记录、具体参与路径与六维工作台

## 产品链路

地图选中对象 → 点击“研判此处” → DSH规划有限检索 → DSH Search找官方记录及开放网页 → 取原文 → 专用Adapter提取字段 → 验证对象与引用 → 简报 → Qwen Decision六维等级 → 持久化结果。

搜索与分析只在明确操作后发生。搜索规划、简报、结构化判断均沿用现有DSH能力边界；没有加入第二个运行时。地图服务的研究入口此前只读取已有快照，此次接入同一公开研究能力。

## 1. 文案与六维

默认卡片保留一句方案、一个下一步、六维图。行动前提仅有实质信息才出现，不再固定顶着“关键条件”标题。原文、解析字段、研究历史和旧分流模型的参数均折叠。旧的泛化“土地用途、权属、腾退未核实”不再用于所有校园场景；同一对象先区分采购工程、专业服务、运营及校外商业。

六维是需求客群、供给竞争、空间工程、实施入口、运营回款、投入交付。供给与需求分开；交通进入可达性和工程条件；企业能力进入投入交付。源文件 `packages/decision/dashboard.ts` 保存每维五级标准。

复用现有Qwen `decision-model-preview` System One API，六个`score`问题与三个原有研究分流问题共用一次请求。官方`score`为从0起算的等级期望值，界面转换为1–5级；校验分布和期望值一致性。置信度低于0.65或没有合格原文的维度显示空值，不补0、不绘制完整填充雷达、不生成综合成功概率。该阈值是当前产品配置，未宣称经业务校准。依据可展开；图上高分不覆盖原有明确阻点。

协议依据：[阿里云Decision Model API](https://help.aliyun.com/en/model-studio/decision-model-api)。

## 2. 公开数据Adapter的真实覆盖

| Adapter | 当前已实现输入 | 返回内容 |
|---|---|---|
| 中国土地市场网 | 官方宗地明细HTML/JSON、地方政府同格式供地公告 | 宗地号、用途、面积、供地方式、受让方、成交价、日期 |
| 四库一平台 | 项目/许可证公开详情HTML/JSON、地方政府许可公告 | 工程编码、建设单位、许可、规模、地址、开竣工 |
| 国家统计局 | `returndata.datanodes/wdnodes`公开查询导出JSON | 行政区、指标、统计期、值、单位、缺失状态 |
| 中国政府采购网 | 公开采购公告HTML/JSON | 采购对象、编号、采购人、预算、限价、成交、截止与履约字段 |

这些是**官方页面与公开导出的字段Adapter**，不是已认证接通四个站点所有私有查询API。HTML/JSON有确定字段才返回记录；统计空值与真实0分开。面积与金额保留原单位，不将公顷当平方米，也不把万元当元。公告中的采购人地址不充当项目地点。

搜索摘要、登录和人机验证页不进入已读原文；接口空结果、访问要求和结构变化分别留状态。不能自动取到的原文保留可追查URL。采购附件PDF/DOCX不在这些HTML/JSON适配器内；可由已有解析流程处理，本轮没有新增附件自动下载链。

复用 `linkedom`、Readability、DSH Web，没有新建搜索客户端或解析服务。

## 3. 流式与界面

分析端点保留原JSON响应；请求`Accept: application/x-ndjson`时返回真实进度和一个终结事件。阶段为资料、搜索、原文、字段、简报、Decision；简报通过校验后先呈现，评分完成再补图。没有模拟逐字输出、虚假百分比，也不展示模型私有推理文本。

一个事件对应实际阶段。连接截断显示中断，取消释放读取器并停止后续结果；切换对象或研究方向忽略旧请求。完成后的过程收起，动画停止。动画只使用短淡入与运行点呼吸；系统减少动态设置会关闭动画。

主色使用石板灰、白和低饱和青绿。模型结果正文15–18px，主标题22px；评分信息14px。SDK地图拥有独立层叠上下文，标记不能盖住面板；证据收起时恢复卡片顶部。移动端使用可滚动底部面板。

## 4. 一键标色修复

- 使用实际视口边界，移除中心小矩形裁切；范围超限提示缩放。
- 识别OSM校园/园区way及relation，保留多边形孔洞；已有园区外的零散建筑继续生成对象。
- 传递真实坐标编码，排除合成项目边界。
- 一轮共享周边资料，按对象过滤。颜色专题切换只重分类；研究方向切换清除旧评分。
- 同一对象、方案、来源版本、模型配置及日期下，重新标色复用已持久化结果，不重跑模型。新边界/方案/来源版本不借用旧颜色。
- 明确阻点优先；缺资料灰色。单维低等级调整路径，高等级可优先研究；综合绿色要求六维都有较高适配，未评维度不凑数。

仍采用矢量GIS分区，并非遥感影像语义分割。没有批量自动分析整张地图。
