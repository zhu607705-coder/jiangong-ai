# 老旧小区改造研判工作台：完整功能演示视频脚本

版本：2026-10-14。主录制入口：`http://127.0.0.1:5173/`。

本稿与 `data/templates/full-feature-video-scenes.json` 采用相同18章、相同顺序和相同key。JSON是配音、字幕与录制章节的共同清单；实际录屏时点由录制结果补入。建议完整片约19分钟，按钮读取和模型结果呈现需要更多时间时自然延长，不按固定时长截掉功能。

## 产品叙事

沿工作人员的一次研究展开：确定空间对象，核对公开资料，问一句话找到原文，拆分并沉淀经验，再比较建设与运营方案，最后形成调查交付物。前段使用求是村真实公开材料；完整报表使用600户、1500人的模拟社区。神经网络试验分别展示七指标合成模型与公告中标价探索。

每次点击都有明确目的，结果出现后停留3—6秒。字幕使用下方逐句讲解，不逐格朗读；每句不超过45字。当前每章5句，旁白115—127汉字，文字采用中文读法，便于中文语音合成。

## 开拍准备

- 服务、地图和现有项目正常可读；建议1920×1080以上、浏览器100%缩放。
- 保留求是村原有材料、草稿和本机方案，不为录制清空存储、删除方案或生成审核结果。
- 真实模式没有完整新研判结果时保留现状；不把旧运行失败剪接成已完成报告。
- 公开原件、AI研究草稿、完整模拟和公告试验遵从界面标记。读取失败如实处理，不后期补造命中或数字。
- 文件下载至本次录制目录，至少实际读回RAG原文包、当前模型试验和成品报表。
- 原约2分钟视频只参考按钮路径，不沿用旧草稿数量或旧功能清单。

## 01｜从地图确定研究对象

章节key：`map`。画面标题：空间范围、初步资料与调查入口。

### 按钮路径与动作

1. 搜索城市、建筑或地点：求是村。
2. 搜索；选择实际对应地点。
3. 图层：城市地图／卫星影像。
4. 框选区域；一键标色；标色依据。
5. 查看调研资料；调研清单。
6. 进入项目研判；展示建立项目表单后取消。

### 逐句配音与字幕

- 从地图开始，把老旧小区的研究对象和范围固定下来。
- 搜索求是村，可以查看地点、周边设施和已有项目。
- 框选范围后，一键标色帮助浏览已有研究和资料缺口。
- 颜色有可展开的依据，附近建筑不会自动继承小区结论。
- 选中对象后，查看调研资料和清单，再进入具体项目。

### 核对结果

- 搜索或选择的实际地点可见。
- 地图图层、范围和读取状态可见。
- 初步资料与调查入口指向正确项目。

### 录制细节

先确认地图实际连接和地点选择，再展示图层、框选与标色。地图标色表示已有项目研究行动和资料覆盖；不将灰色解释为不适合改造。没有返回边界时保留提示，继续点选已有项目。新建项目只浏览表单后取消，不在录制中创建重复真实项目。

## 02｜项目与公开资料

章节key：`intelligence`。画面标题：已有资料覆盖、原文查阅与项目归档。

### 按钮路径与动作

1. 项目数据；项目资料。
2. 资料检索；检索：老旧小区。
3. 城市范围；资料类别；应用。
4. 打开实际资料标题。
5. 原文摘录；查看原始来源。
6. 加入研究项目入口，不重复导入现有原文。

### 逐句配音与字幕

- 项目数据面板集中展示已有项目、来源和资料缺口。
- 切到资料检索，可以按小区、城市和类别查找已沉淀资料。
- 打开一条资料，查看原文摘录、日期和原始来源。
- 已有公开原文可以加入指定研究项目，保留出处。
- 资料加入后还需要核对对象和口径，才形成具体判断。

### 核对结果

- 项目资料显示当前真实数量。
- 检索命中有原文、来源及处理状态。
- 加入原文入口展示项目范围。

### 录制细节

实际入口是地图的“项目数据”图标→“项目与数据”→“资料检索”。检索复用已沉淀资料，选择当次真正返回的标题。已有原文不重复加入求是村；展示加入项目入口与原文出处即可。项目计数以录制当时页面为准。

### 逐句配音与字幕

- 添加信源表单有地址和读取方式。

### 录制细节

1. 原文详情；记录分类与入选反馈。
2. 展示类别、同源家族、样本用途和核对说明。
3. 校准；评测集合：开发集／留出集。
4. 查看评测。
5. 导出评测样本入口，不提交未经人工核对的标签。

### 逐句配音与字幕

- 开发集用于调整，留出集用于检查调整后的表现。
- 查看评测时，页面显示实际样本数和可计算的指标。
- 还没有标签的项目保留空值，已核对样本可以导出。

### 核对结果

- 开发集和留出集可选择。
- 评测展示真实样本或空值。
- 反馈与评测导出入口明确。

### 录制细节

在原文详情展示反馈字段，在校准页读实际评测。没有人工标签时保留空值，不制造查准率或查全率。人工反馈、来源家族与用途授权需要实际核对，不为视频填造真实标签。

## 05｜直接问资料，回到确切原句

章节key：`floating_rag`。画面标题：问题检索、原文出处与同版本精准跳转。

### 按钮路径与动作

1. 直接问资料；选择求是村。
2. 供水范围；查找依据。
3. 查看材料版本与范围。
4. 定位对应资料 →。
5. 手动切另一片段；再次点击定位。
6. 限定资料范围；保持AI研究草稿默认排除；Esc收起。

### 逐句配音与字幕

- 点击直接问资料，用一句问题查找当前项目中的原文。
- 以二次供水为例，核对涉及哪些楼栋和住户。
- 四幢共二百五十二户，要按原文范围和当时时点理解。
- 排除楼栋也能找到明确措辞，再点击定位对应资料。
- 工作台会回到同版本原件，聚焦具体摘录，继续自由浏览。

### 核对结果

- 检索项目正确、公开原件默认范围明确。
- 252户及排除楼栋有逐字命中。
- 精准跳转选择同版本原件和首句。
- 用户手动切片后不会被持续重选。

### 录制细节

建议问题：“二次供水改造涉及哪些楼栋和户数，哪些楼栋被排除？”选252户所在命中再定位。验证同版本原件、line定位与252户首句实际聚焦；手动切片后再检索并再次定位。252户按2023公开原文的四幢范围理解，拟实施、排除和后续现况分别记录。

### 核对结果

- 不同材料按来源性质分区。
- 定位完整片段与前后文可读。

- 原文及审核状态读回一致。

### 录制细节

选择供水或维护等实际存在的举措，比较公开原件与AI研究草稿分区。展示已登记引文和原文提及的区别。先导出单原件Markdown，再导出全材料JSON；读回一段正文、定位、文档哈希及审核状态。表格仅取得预览时说明截取范围。

## 07｜原件怎样拆成证据

章节key：`evidence_split`。画面标题：原文片段、实际引用、举措与资料覆盖。

### 按钮路径与动作

1. 材料怎样拆成证据；选择拆分原件。
2. 已被引用的片段；点击原文。
3. 查看对象与阶段；查看材料版本与拆分标识。
4. 全部原文片段。
5. 导入数据关系图；字段；选择原件或表。
6. 调研覆盖；点击对象维度；查看未匹配记录。

### 逐句配音与字幕

- 材料先解析成片段，再查看哪些字段和举措引用了原文。
- 选择二次供水原件，点一段摘录，查看对应证据和对象。
- 引用关联保留文档版本和原文定位，同名举措可以收拢展示。
- 切换全部片段，未被引用的上下文仍然可读。
- 关系图和资料覆盖帮助核对文件结构，以及各对象的缺项。

### 核对结果

- 片段与关联字段同文档同版本同定位。
- 全部片段与被引用片段分开。
- 重复显示值归并且来源仍可展开。
- 结构关系及对象覆盖可操作。

### 录制细节

默认被引用片段与全部原文片段分别展示；背景切分本身不计为字段引用。展开同对象、同阶段的归并值时保留原始卡及审核状态。结构图选择文件或表，资料覆盖选择对象维度，未绑定行保持未匹配。

4. 原文举措、导师因素政策与技能蒸馏。
5. 切分原文：二次供水公开原件。
6. 检索已审核经验入口；展示实际结果或空状态。

### 逐句配音与字幕

- 经验库记录一次决策怎样发生，保留问题、条件和来源。
- 提议、实际决策、实施和结果分别展示，避免混为一件事。
- 展开举措组，可以查看原卡、引用和当前审核状态。
- 普通材料可以手动整理，也能按原文提取措施草稿。
- 草稿里的缺项留给复核，审核完成后才进入已审核经验检索。

### 核对结果

- 举措组保留原卡与引用。
- 提议、决策、实施、结果分别可见。
- 编辑与手动整理入口可读。
- 未自动批准草稿。

### 录制细节

先打开已有草稿卡和引用，浏览编辑表单后取消。切分原文为只读操作；提取措施会保存或复用草稿，如实展示接口结果。不要在录制中批准经验卡。提议、实际决策、实施和结果都按材料原文保留，不把计划改成已完成。

- 分组展示真实结果与政策版本。
