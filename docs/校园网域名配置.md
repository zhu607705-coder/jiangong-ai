## 服务器配置

阿里云云解析 DNS 的 `@`、`www` 两条记录已启用，TTL 为 600 秒。权威服务器为 `dns3.hichina.com`、`dns4.hichina.com`；已分别查得目标地址。

Nginx 在原 `10.70.223.113:80` 监听中增加两个 `server_name`，继续将请求转发至 `127.0.0.1:4310`。上传限制、请求限速、650 秒代理等待时间、校园协作模式与现有项目保持。

应用复用 `apps/host/request-origin.ts`，新增可选的 `TRUSTED_PUBLIC_ORIGINS` 配置，按逗号分隔明确列出额外 Origin。该部署保留主 Origin，并增加两个域名：

```dotenv
TRUSTED_PUBLIC_ORIGIN=http://10.70.223.113
TRUSTED_PUBLIC_ORIGINS=http://laneanew.cn,http://www.laneanew.cn
PUBLIC_READ_ONLY=false
COLLABORATIVE_WORKSPACE=true
```

配置仅接受完整 HTTP(S) Origin，不接受通配符、用户名密码、路径或任意请求来源。未带工作台请求标识、来自未授权 Origin 的写请求仍返回 403。
