## 自动续签

首次签发通过手动 DNS-01 完成。随后已使用专用阿里云 DNS 身份执行 `certbot reconfigure`，通过 Let’s Encrypt 测试环境的自动验证，并运行 Nginx 检查及重载钩子。正式续签配置已改为 `authenticator = dns-aliyun`，CA 地址仍为正式 Let’s Encrypt 服务。

`haizhizi-certbot-renew.timer` 已启用并处于 active 状态，按**北京时间每天 00:00、12:00** 检查，另加不超过一小时的随机延迟。Certbot 只在证书进入续签窗口时申请新证书；成功后 `haizhizi-nginx.sh` 检查并重载 Nginx。

```sh
sudo systemctl status haizhizi-certbot-renew.timer
sudo systemctl list-timers haizhizi-certbot-renew.timer
sudo systemctl status haizhizi-certbot-renew.service
```

凭据长期保存于 `/etc/letsencrypt/aliyun.ini`，root 所有、权限 0600；云端临时副本已清理，凭据正文未进入代码或交付记录。部署配置位于 `/etc/letsencrypt/haizhizi-renew.env`，当前 DNS API 使用服务器直连。

包装入口 `scripts/haizhizi-certbot.py` 导入原插件，保留其签名与认证逻辑。对清理行为按 TXT 名称、类型和本次验证值精确匹配，避免同名记录含有其他验证值时被误删。精确清理与代理隔离共 4 项定向检查通过。
