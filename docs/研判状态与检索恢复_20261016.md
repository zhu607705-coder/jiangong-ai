# 研判状态、证据版本与检索恢复

本轮保留 DeepSeek Harness，修复地图研判恢复、六维独立成果、问答关键路径和情报库衔接。源码基线为 `cfb4e4523ac58f4392fdd73aa15043354c6c813b`；实际部署另记录提交及文件散列。

## 完成状态与人工动作

地图研判的 `completion` 分开记录执行、证据覆盖与资料版本。一次调用可以执行完成，同时仍有三个维度待补证。未知分数保持为空，不作为零分，不触发无限自动补查。

| 动作 | 行为 |
| --- | --- |
| 读取已保存结果 | GET，只读恢复，重新核对来源时效与资料范围 |
| 补查缺失资料 | 显式绕过已完成缓存，重新取证和研究 |
| 按现有资料重评 | 不外搜，复用同快照证据重新判断；失效资料先刷新 |

失败尝试保留已有简报、有效评分和来源。地图尝试另存于 `map-screening/analysis-attempts`，本轮调用记录与历史记录分开，避免连续重试使单轮记录超过契约容量。整体方案也提供按现有公开资料重评；涉及内部文件时，回到原材料选择与本轮 AI 授权流程。

## 六维成果独立保留

在模型交付可读结构后、整份方案校验前，独立提取六维现况及推理情景，绑定项目资料版本与 `input_hash`。每个现况字段单独校验；工作包不合格不再丢弃有效维度，重复或损坏维度留出补查位置。非未知现况等级缺少本对象依据时，保留分析文字并标注待补充，图表不将其冒充实测评分。

“六维现况”可在未形成整体方案时进入。六个维度始终有阅读位置，已有分析与具体缺项并列展示；补充问卷、助餐人次、分幢电梯利用率、责任与资金台账的要求进入原轮次的 `missing_materials`。改后目标仍属于所选方案。

地图 Qwen 图表示概率加权适配等级；方案图用低／中／高对应 1／3／5。两图继续分别标注对象、目的和标尺，推理情景与证据画像可切换。

## 原文先返回，索引在后台继续

问答接口兼容原 JSON，增加 `application/x-ndjson`。实际事件顺序为 `originals` → `complete`；模型不可用时原文仍可阅读，错误事件不会清空原文。

提问时只读取已存在索引，不再补建全库索引。已有概念索引与有界原文候选进入语义判读，最多 60 个窗口且目录不超过 24,000 字符。排序、引用与权限继续复用原实现，未扫描部分明确留待后续检索。

增量索引复用已有 `intel_jobs` 和同一任务 worker，新增任务类型 `rag_index`，未新增调度器。上传、公开原文导入和检索可提交任务；任务只保存项目、拥有者、版本及来源指纹。运行前重新核对这些字段，变化时不处理旧任务。已有窗口按内容散列复用；后台每个任务最多处理 3 批、每批 6 个窗口，在任务时限前交回部分成果。有进展而尚有缺项时继续下一任务，无进展时停止本次续批。真实首轮曾到达旧任务超时，已保留该回执；小批次调整后继续读取已保存窗口。后台默认只处理公开材料，内部材料仍按本轮授权显式处理。

## 结构回读与情报衔接

直接问答与专家回读复用同一词面／主题匹配函数，主题不再单独作为硬性排除。标题与正文参与召回，明确不同楼幢或单元不靠语义相似度混用。命中项可附同版本的所属标题、表头及相邻原文，各自保留定位和 ID，回答按这些独立片段引用；没有把拼接文字当作一段连续原文。

结果区以“资料范围 → 可检索原文 → 本轮命中 → 回答引文”显示本次实际使用过程，可进入原文、引用与排除原因。

整体研究用 `intelligencePolicy` 分别指定已有原文读取、新来源沉淀及新鲜度检查，替代该入口原有的整体关闭。召回仍按对象、范围和研判时点取得来源，本轮冻结其文本；新取得原文沉淀后供下一轮复用。

方案正文、标题与卡片说明的篇幅不再作为整包失败条件，原文和解释保留；ID、定位、单位、字段类型及权限继续校验。界面负责摘要与展开。

## 失败回执与部署识别

DSH 流式调用在 `finally` 保存回执，包含异常和提前终止。`usage_status=unknown` 表示尚未收到用量，界面显示“用量尚未返回”；兼容数值字段中的初始零值不作为真实零消耗。服务商私有错误正文不进入产品回执。

`/api/ready` 增加 `protocol_version` 与经校验的 `release_commit`，部署收据保存实际源文件散列，以区分源码版本、线上版本与模型返回问题。

## 验收与来源定位对照

定向回归覆盖完成缓存的主动补查、无外搜重评、整包失败保留有效维度、零命中维度占位、HTTP 原文先返回、不同单元隔离、同版本结构回读、内部资料不送后台模型、任务续批及失败流回执。

`scripts/evaluate-research-retrieval.ts` 使用求是村已归档公开原文和 8 个中文问题，保持同一 Python BM25，对照严格正文主题筛选与结构回读协议。两组来源命中均为 **7/8**：新协议找到回迁延期通知，拆六建四的目标来源在前五名中落后。此结果用于后续排序优化；它没有证明回答准确率提高。该实验模型调用为 0、业务事实写入为 0，标签只存在评测脚本中。
