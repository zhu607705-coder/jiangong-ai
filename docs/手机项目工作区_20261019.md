# 手机项目工作区

手机默认显示一项当前工作，按页内按钮切换；列表按上一条、下一条翻看。保留现有六个独立主页面，导航菜单继续负责跨业务切换。

| 项目页 | 手机局部页面 |
| --- | --- |
| 总览 | 结论、对象、调查、进度 |
| 资料与条件 | 资料、对象、条件、补充 |
| 改造研判 | 方向、六维、条件、对标 |
| 方案与测算 | 方案、举措、资金、运营 |
| 调查任务 | 调查、条件、回填、历史 |
| 成果与版本 | 成果、变化、轮次、导出 |

正文15px、标题20px；小屏正文14px、标题18px。输入框保留16px，避免手机编辑时自动放大。摘要与按钮均在固定高度工作区中，不需要上下滑动寻找下一项；完整说明、原文和复杂表单按需打开，明细区域允许阅读滚动。

总览分别保留更新方向、投入建议、财务与社会收益。模式卡共享既有RenewalModePanel的实际状态、条件与阶段；未开始时不预设结论。用户选择研究方向后，方案和目标沿用相同方向过滤。独立六维结果在整体方案未完成时继续可见，推理暂估仍与证据等级分列。

任务ID复用buildProjectTasks，点按调查卡直接打开原任务抽屉，保留上传、粘贴、字段提取与下一轮研判入口。原工作区保持挂载，切回摘要不会清除未提交表单。工作建议复用原Decision上下文和调用；资料查询复用原悬浮RAG工具。

阶段未知的历史金额不在手机卡片合成可比估算区间，而显示原件记录和分列核对入口；原数据与完整工作区仍保留。复用projectOverviewState、renewalCheckEmphasis和现有来源定位，不新增模型、存储或判定规则。

适用手机宽度≤760px的老旧小区项目工作页。完整模拟工具及历史通用项目保留其原有工作区，桌面呈现保持原结构。

验证按相关契约、实际手机尺寸和正式站回读分别记录。已验证390×844下六页摘要区scrollHeight=clientHeight=788；320×568下同口径为512，操作与翻页按钮在屏内。预览中的未提交测算输入返回摘要后保留，测试值随后恢复，不写项目事实。正式部署回执与截图见本轮mobile-workspace工件。
