# 浙大七校区：从笼统“校园更新”到具体参与路径

**研究时点：2026-09-28。** 面向建投、工程与运营企业的前期研判。案例说明、六维判断与建议由本次分析形成；没有把模型未执行的评分填成数字。

## 1. 先决定研究哪种生意

本案例建议优先研究“校方采购的工程及专业服务”，再单独研究“校外面向校园人群的商业”。对于前者，关键问题是采购标包、交付能力、履约组织与回款；对于后者，关键问题是可进入的经营空间、实际付费客群、校内替代供给与租赁成本。两类路径不能共用一段土地腾退提示。

华家池的立面修缮、舟山的宿舍修缮、海宁的校园物业均出现了具体采购结果；玉泉永谦场馆则已有更新后的运营记录。这些材料让研究对象从“整个校区是否能开发”收敛到“哪一栋、哪一类合同、哪一个服务窗口”。[S1][S2][S4][S5]

建议把产品分成三个能力包：**分栋更新交付**（清单、组织、验收）、**专业设施运维**（设备、响应、工单）、**跨校区轻型供应服务**（配件、周转、配送）。这些是分析提出的业务组织方式，不是公告已批准的合同范围。

## 2. 六维怎样改变判断

| 维度 | 真正要回答的事 | 有用证据 |
|---|---|---|
| 需求客群 | 谁提出任务、谁使用、需求发生在什么时候？ | 采购需求、运营记录、使用与故障数据 |
| 供给竞争 | 现有设施或供应商已经满足了什么？还有什么缺口？ | 成交方、现有服务范围、空置与替代供给 |
| 空间工程 | 具体建筑、设备和功能能否匹配方案？ | 测绘、设备台账、清单、检测和接口 |
| 实施入口 | 企业能通过哪一合同或协作路径参与？ | 采购阶段、资格、授权与交付责任 |
| 运营回款 | 谁付钱、按什么成果验收、多久回款？ | 合同、支付、绩效、质保与收入来源 |
| 投入交付 | 要投入什么资源、能否按窗口完成？ | 工期、施工条件、人员、备件与现金占用 |

交通放回客群可达性和现场交付条件，不另占一维；金额不是“收益”，中标方也不是“竞争强度评分”。一至五级适配由运行时 Decision 模型依据各维度原文证据评价，证据空缺保持空白。当前七案例提供定性研究，不伪造已调用模型的数值。

## 4. 七校区逐一研判

### 紫金港｜从单体修缮、测绘和机电服务切入，按采购标包准备交付方案。

**建议参与方式。** 将测绘与现状盘点能力、单栋修缮、机电运维分别形成可采购服务；由具备相应能力的团队选择一个标包入口。
**合同与付费入口。** 已发布工程与测绘采购的采购人为浙江大学；具体付款节点取合同。 [S9] [S10]

| 维度 | 本次判断 | 下一项真正有用的资料 |
|---|---|---|
| 需求客群 | 采购摘要已出现立面修缮和测绘任务。 | 取得采购文件正文。 |
| 供给竞争 | 已存在中标供应商，不能把已成交标包当开放订单。 | 核查下一标包与竞争者能力。 |
| 空间工程 | 可聚焦单栋外围护及现状数据，不先假设整体新建。 | 读取图纸、清单和检测需求。 |
| 实施入口 | 通过学校具体工程或测绘标包进入。 | 确认公告阶段和投标资格。 |
| 运营回款 | 工程结算与测绘服务费是拟研究收入路径。 | 取得结算、验收及质保约定。 |
| 投入交付 | 不同专业分包能力、进度与垫资分别核算。 | 按实际工程量与工期编制成本。 |

**带去谈的交付物：** 单栋现状图、工程量清单、设备接口表和教学期施工组织方案。
**现在做的一步：** 回读立面改造及测绘文件，列清交付界面与下一轮采购窗口。
**另一条路径：** 校外商业作为独立选址题，先调查出入口客流和替代供给，不把校内建筑直接作为开发对象。

### 玉泉｜永谦场馆已更新，研究系统维护、运行保障和场地效率提升。

**建议参与方式。** 围绕已经投入使用的活动场馆，提出设备台账、故障预防、活动前检查和会务系统运维服务。
**合同与付费入口。** 先识别学校与现有会务运营方的采购职责；付款主体以实际服务合同为准。 [S4]

| 维度 | 本次判断 | 下一项真正有用的资料 |
|---|---|---|
| 需求客群 | 运营方发布了更新及试运行记录。 | 取得当前活动及故障工单。 |
| 供给竞争 | 场馆已有会务团队，应先识别其外采缺口。 | 核对现有供应商与质保覆盖。 |
| 空间工程 | 对象是已更新的会议与演出空间。 | 读取设备清单和接口。 |
| 实施入口 | 以新增采购或既有授权服务边界为入口。 | 核对可采购的服务范围。 |
| 运营回款 | 先研究运维服务费，不从预订量推导利润。 | 取得采购预算和结算口径。 |
| 投入交付 | 应按活动频次和设备系统配置值守资源。 | 测算排班、备件与响应成本。 |

**带去谈的交付物：** 场馆设备台账、活动前检查表、工单闭环和分级响应服务方案。
**现在做的一步：** 核查现有维保范围与设备质保期，再拆分新增服务清单。
**另一条路径：** 在校外做会议配套服务需要另查可达性、场地使用及付费客户；校内场馆升级已经形成替代供给。

### 西溪｜一食堂改造已中标，研究后续专业工程与运维需求，而非重复开店。

**建议参与方式。** 从食堂建筑改造所需的专业工程界面入手，形成施工与设备维护能力方案；设备范围仍由采购文件确定。
**合同与付费入口。** 改造采购人为浙江大学；运营承包不能从工程中标公告推定。 [S3] [S7]

| 维度 | 本次判断 | 下一项真正有用的资料 |
|---|---|---|
| 需求客群 | 公告摘要明确一食堂改造已成交。 | 核对工程范围与实际进度。 |
| 供给竞争 | 校内已有食堂供给，新增外部餐饮先看差异需求。 | 调查服务窗口及周边替代供给。 |
| 空间工程 | 可研究建筑与设备的改造界面。 | 读取厨房、机电与消防接口资料。 |
| 实施入口 | 既有中标包已结束竞争，关注后续独立包。 | 查后续公告，确认采购关系。 |
| 运营回款 | 工程收入与食堂经营收入须分别评价。 | 分别取得工程和运营合同条件。 |
| 投入交付 | 施工组织需衔接在校供应。 | 核实停供窗口、临时供应及交付时间。 |

**带去谈的交付物：** 建筑、设备与运维接口清单；错峰施工和临时供应协调方案。
**现在做的一步：** 取得食堂改造采购文件，分清建筑工程、设备采购及运营合同。
**另一条路径：** 先做短期供应或工程服务能力验证，避免依据学校规模直接承租大面积校外商业。

### 华家池｜以图书馆立面修缮为切口，准备分区施工与验收资料服务。

**建议参与方式。** 把外围护修缮、现场组织和质量验收作为工程能力包，利用已成交项目识别类似后续需求。
**合同与付费入口。** 采购人为浙江大学，现有成交供应商为浙江盈科建设工程有限公司。 [S1] [S7]

| 维度 | 本次判断 | 下一项真正有用的资料 |
|---|---|---|
| 需求客群 | 281.24万元修缮成交记录明确。 | 确认当前进度及其他楼栋需求。 |
| 供给竞争 | 已有成交供应商，后续包才是新参与入口。 | 查询后续标包和资质要求。 |
| 空间工程 | 具体对象为图书馆外立面。 | 读取立面清单、检测及工艺要求。 |
| 实施入口 | 学校工程采购路径明确。 | 确认新采购或合作授权范围。 |
| 运营回款 | 金额锚点可用于规模识别，收益取决于实际成本。 | 取得付款、质保、变更条款。 |
| 投入交付 | 公告写明合同签订后75日历天。 | 核查开工日、场地及教学安排。 |

**带去谈的交付物：** 按立面分区的病害记录、清单复核、样板段和施工扰动安排。
**现在做的一步：** 回读修缮清单与75天工期安排，核查后续楼栋采购。
**另一条路径：** 校外面向培训活动的服务另立研究对象，用真实活动与住宿订单检验需求。

**合同与付费入口。** 优先核对后勤水电保障与修建工程中心的采购职责及当期服务商。 [S8] [S6]

| 维度 | 本次判断 | 下一项真正有用的资料 |

| 供给竞争 | 运行服务已由既有组织承担。 | 了解现有服务商和备件来源。 |
| 空间工程 | 需沿具体变配电系统和服务区域开展研究。 | 取得实际系统图、设备台账。 |
| 实施入口 | 当前独立采购窗口仍需检索。 | 查当期采购文件。 |

**另一条路径：** 不将2025年停电通知当作2026年施工安排；也不把历史建筑外观当作改变使用用途的依据。

## 5. 一个单独的当前采购线索

9月22日发布的“配电与管控单元”公告摘要给出136万元预算、10月8日文件获取截止和10月15日投标截止。[S11] 本轮原文返回403，校园位置与具体设备功能尚未确认。应放入“待定位采购线索”，先读取需求再判断是否与建筑工程能力相关，而不是因为采购人地址在紫金港就把它标到紫金港图块。

## 6. 从资料到下一步，不再留下一句“未核实”

对不同企业，下一步应交付不同成果。**施工企业**提交一个单栋清单复核与施工窗口方案；**运营企业**提交服务边界、验收指标及成本分解；**建投平台**先确认可承担的是工程采购、资产运营还是校外商业，不把学校采购额当成可投资资产价值。

校外餐饮研究还应控制季节因素：学校寒假安排保留基础供应，但调整了部分窗口、时间和服务地点。[S7] 建议现场调查至少分工作日、周末和假期三个情境，记录店铺实际营业、消费时段及空铺；检验一个明确服务缺口后，再讨论租赁面积。

首个可以验证的业务成果不是完成七校区“总评分”，而是形成一张有对象、采购阶段、付款方、交付物和下次窗口的机会卡。对于已成交事项，记录其后续维保或下一批采购线索；对于当前公告，先确认需求与资格；对于运营新闻，先取得当前工单与服务范围。
