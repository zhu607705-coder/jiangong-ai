# 元宝搜索接入

元宝搜索作为现有DSH Web的新增搜索提供方，配置为`RESEARCH_WEB_PROVIDER=tencent_wsa`时优先使用。项目调研、RAG外网补查、原生搜索信源和公开资料扩库共用`createPublicWebTools`；RSS与网页列表继续原HTTP读取，现有原件解析、入库、版本、AIHOT研读和Topic编纂保持同一流程。未配置Key、空结果、服务错误或本地额度耗尽时使用独立DeepSeek Search；回执保留真实提供方和原因。同一轮发生超时、鉴权或限流后跳过后续腾讯请求，减少重复等待。

## 官方接口与来源

- [服务API Key接入](https://cloud.tencent.com/document/product/1806/130615)：`POST https://api.wsa.cloud.tencent.com/SearchPro`，通过`Authorization: Bearer`传服务Key，无需腾讯云主账号SecretId/SecretKey。
- [SearchPro参数与结果](https://cloud.tencent.com/document/product/1806/121811)：`Pages`中的每项为JSON字符串；`content`是动态摘要。摘要只用于发现和排序，不能作为已读取全文；后续复用既有Fetch取得原文。
- [产品与规格](https://cloud.tencent.com/product/wsa)：极速/标准/旗舰的公开标价分别为14/20/26元每千次。公告中每月2000次免费额度尚待本账号控制台核对；请求回执保持`billing_state=unknown`，不把本地次数当作云账号剩余额度。

自动模式只发送全版本支持的Query及可识别的单个Site条件。明确设置标准或旗舰版后才发送Cnt、可选Industry。返回的RequestId与服务版本记录在回执；非法、内网及重复URL过滤。密钥只发送固定HTTPS官方入口，禁止跳转，不写入返回、浏览器或日志。

## 配置

服务Key使用`TENCENTCLOUD_WSA_APIKEY`；超时默认7000ms；`TENCENT_WSA_EDITION=auto`；`TENCENT_WSA_INDUSTRY`默认空，可选gov/news/acad/finance。默认配置仍为原DeepSeek通道，已有服务器Key缺失时不伪称已启用腾讯。

Key可由使用者保存到仓库外的私密单行文件，然后运行：

```powershell
python scripts/configure-tencent-wsa.py --key-file C:/Users/123/.codex/secrets/tencent-wsa.key
```

辅助脚本使用已配置的SSH，在服务器原server.env中原子更新Key与提供方，文件及备份权限0600，保留其他配置；不自动重启。运行前先部署对应代码；配置后在无活动研究轮次时重启原服务并做少量真实查询。服务Key创建与腾讯云协议/套餐开通由账号持有人完成。

## 额度与原文沉淀

调用上限默认每北京时间自然月2000次尝试，配置只可降低至0–2000。`intel_provider_calls`沿用同一IntelRepository数据库，以既有单例行锁保证并发请求先留回执再发出；超时、失败和不确定请求继续占次数，重启不清零。月度表是调用记录，不增加后台调度器。上限仅覆盖本工作台，同账号其他工具消费需要在控制台核对。

公开自动扩库仍保留原日搜索1000、Fetch200、金额6元限制，模型日预算100不变。腾讯请求先按扣除赠额前的最高0.026元预留，返回版本已知后按标价更新估算；不能确认的费用保留未知，不假定失败免费。自动采集回退到DeepSeek后仍按原独立API回执计费。取得原文后沿用persist归档Markdown/JSON/片段，再进入AIHOT与Topic。

## 验证范围

28项定向检查覆盖请求字段、字符串结果解析、摘要/正文分离、URL过滤、各类失败回退、取消、工厂路由、跨月额度与原采集/HTTP回归。结果见`research/test_results/tencent-wsa-tests-20261021.log`。真实接口成功与质量比较仍需要服务Key；不得将协议夹具输出或腾讯宣传的索引耗时当作本工作台实测。

运行状态可从`GET /api/intelligence/status`的`search_provider`和`additional_search`读取，包含配置状态、本月尝试数、限额、回退及计费核对状态，不返回密钥。

部署回读：服务器13个运行文件已更新，43项目及历史不变，原DeepSeek仍为活动提供方；元宝Key缺失，月度已用0/2000。本轮缺Key真实回退耗时405ms、返回4条DeepSeek结果，仅验证回退可用；不是元宝成功请求或质量/速度比较。类型检查及生产构建通过。Key配置后的原生检索、抓取与同题质量比较仍待执行。
