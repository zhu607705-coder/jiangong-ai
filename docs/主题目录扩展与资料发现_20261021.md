# 主题目录扩展与资料发现

从3项试点扩展为21项研究问题，按方向与条件、安全与工程、公共服务、协商与交付、资金与运营五组组织。目录位于packages/intelligence/topic-catalog.ts，由前后端共用，新增主题后相关主题链接直接使用同一标题与标识。

主题范围参考[北京市老旧小区改造工作改革方案](https://www.beijing.gov.cn/zhengce/zfwj/202211/t20221115_2859698.html)中工程、公共服务、协商、出资与管护内容；五组21项是本工作台的研究组织方式。政策地区、时间与实施条件随原文保留。现有库的模式、安全、消防、居民协商、资金与物业六组实检及来源例子见topic-expansion-discovery-20261021.json。

原有供水、电梯、社区食堂标识和历史版本保留。目录新增改造模式、权属规划、结构安全、排水防涝、屋面外墙、消防、燃气电力、停车充电、无障碍、养老健康、儿童托育、公共空间、居民协商、招采交付、资金平衡、工程造价、物业管护、运营绩效。每个主题有独立问题、原文词组与适用场景。

目录在原intel_documents行维护主题归属与公开范围元数据，统计公开、非合成、可用于研究的当前原文；计数覆盖资料库，而编纂仍优先读取当前主题的最多400个候选、12份原件窗口。既有资料按当前目录修订分批补齐元数据，新资料在原入库事务内同步登记；目录读取不扫描原文，也不预先为所有主题切分正文。已保存页的访问范围批量核对；精确资料版本状态在进入主题时核对。旧页不会被目录扩展覆盖。

界面提供主题搜索、五组筛选和局部翻页；桌面每页3项，手机每页1项，返回目录保留筛选。任务排队、处理中与预算等待分别呈现，刷新列表不产生模型调用。统一使用现有100次模型日预算，编纂通过原intel_jobs/DSH执行，不增加后台调度器。

编纂提示改为只列与当前主题相关的内部调查字段。城市未明确时不凭街道名称补城市；跨地区/年度/口径差异归案例比较，技术做法的推广和因果建议留在推理线索，逐条保留原文引用。引用正确与专业判断审核分别记录。

实库性能修正：逐主题聚合曾导致超时，合并扫描后首次仍约10.5秒；现改为原件入库时的元数据投影，目录查询使用小字段计数。投影与原件同库同事务，目录修订触发一次增量补齐，不新增搜索客户端或调度器。
