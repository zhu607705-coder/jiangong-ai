# 地图对象研判 v1

## 界面与交互

沿用参考图的地图主画布、窄导航、点选详情；删除常驻数量面板、雷达图和密集说明。默认保留搜索、标色与图层。选择对象后出现最多两条“场所线索 → 调查方向”；点击“研判此处”才调用 DSH。原文、日期、场所样本与因子依据收进“查看依据”。

地图摘要上限64字，机会、关键条件与下一步各一项、各48字；项目研判摘要96字。旧项目长摘要以三行折叠展示，完整文本仍在项目研究页。通用提示“AI 生成与搜索可能存在错误”只出现在全局底部和项目确认处。

## 办公线索怎样使用

`work_live` 沿用高德分类查询；在场所样本中匹配“商务／写字楼／办公／产业园”，展示至多两个名称。它触发的是工作日餐饮、企业服务、存量办公改造的调查路径。具体调查项是入驻企业、实际到岗、空置与同类供给；这些调查结果才能成为需求、运营条件。

商业配套样本用于提出竞争与互补调查；交通节点用于提出入口、过街和步行衔接调查。地图记录数只保留在原始接口兼容字段，既不作为摘要结论，也不参与颜色。

## 区块算法与坐标

`services/capabilities/map_regions.py` 在已有鉴权能力服务内运行。Shapely执行修复、相交、差集、polygonize及拓扑保持简化；pyproj负责米制面积；eviltransform负责GCJ-02/WGS84转换。每轮只向固定Overpass端点发送当前范围坐标。

顺序为：已有项目Polygon → OSM园区边界 → 地面道路／铁路与水系围合的街区 → 没有上述对象时采用建筑轮廓。排除水域与已占区域；桥梁、隧道不作为地面分界。屏幕边缘参与裁切；只有视口外框而没有分割对象时不生成街区。面积阈值25／500／1500平方米分别用于建筑／园区／街区碎片过滤。

每轮最多24对象、6000来源要素、8MB响应；支持多边形孔洞，锚点取面内代表点。范围冻结，拖图不重跑。对象太多时显示范围提示；缺少边界时保留点选。此次实现为矢量GIS分区，影像目标检测和语义分割尚未接入。

一轮共享四类场所查询及一次地址查询，随后按各多边形过滤样本；不对每个对象重新搜索或调用模型。每类至多25个场所样本，完整调查由用户点选发起。更换颜色专题复用本轮快照。缓存、取消与过期检查保留。

## 标色规则

六维：实施条件、空间适配、使用需求、运营组织、资源安排、交通衔接。实现中采用版本化检查表，不设记录数权重或收益分数。

| 维度 | 进入检查表的明确事实 |
|---|---|
| 实施 | 用途适配、权利取得、腾退安排 |
| 空间 | 结构适配、消防路径 |
| 需求 | 使用需求、同类供给消化 |
| 运营 | 运营主体、收入来源 |
| 资源 | 分期资金、改造投入 |
| 交通 | 步行接驳 |

结构化事实使用 `screening.<field>`，布尔值，并带 `source_id / object_ref / locator / observed_at`。同一对象必须满足该维度全部条件；不同对象、不同项目不能拼接。来源需真实且有正文；当前版本采用180天复核窗口，此窗口是产品研究规则，待真实项目评测校准。城市背景不进入对象判定。

绿色“进入研究”：该专题必要条件已有依据；综合专题需前五维同时满足。蓝色“核查条件”：部分条件已有依据或资料分歧。琥珀色“存在阻点”：有明确不满足条件。灰色“待研判”：暂无可用条件。

DSH提取的条件需附选中项目公开原文的精确短引文，先作为待核线索。宿主核对来源、对象范围、原文与时间；模型不能覆盖本地已有的明确阻点。`packages/maps/decision-factors.ts`是标色规则的唯一入口。

## Skill与50案例

统一入口 `runtime/skills/investment-brief/SKILL.md`，由真实DSH根会话和子代理加载；地图及完整项目路径生成均按主题选最多三个案例。检查表和风格门禁在宿主执行，格式问题可修复重试，不通过删掉否定句来“美化”结果。

`references/cases.json`与同目录README保存50例：第一批28例、第二批前22例，按机制覆盖挑选。每例包含公开做法、商业解读、下一步、迁移条件、发布日期及页码／案例定位。事实与本项目解读分字段。案例用于提示推理机制，不充当当前区域事实或成功率标注。

资料来源：住房城乡建设部两批城市更新经验做法（2024-01-24、2025-03-11）。第一批核对发布正文；第二批核对公开PDF对应页。链接及定位保存在每条记录中；不把原始大体积PDF打包进仓库。

## 检查与边界

本地：92项JS测试、10项空间测试、8项浏览器交互检查、TypeScript/Vite构建通过。浏览器使用完整应用组件和合成的地图／接口样本，检查不主动研判、选择复用快照、一次显式模型调用、切换专题不重查、证据展开、桌面与移动布局。脚本：`tests/browser/map-workspace.mjs`，可用 `CHROMIUM_PATH` 指定浏览器。

本轮未使用实际高德／Overpass／DeepSeek凭据联调；真实网络覆盖、返回速度及研判效用仍需环境验收。完整Python回归由PR CI安装依赖后执行；本地环境缺少jieba等既有依赖，不把未执行检查登记为通过。
