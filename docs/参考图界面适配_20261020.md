# 三张参考图的界面适配

参照 `reference/1.png`（项目总览）、`2.png`（地图）、`3.png`（项目空间）。

- 深蓝全局栏、图标项目导航和品牌顶栏，项目页面沿用原路由及可用状态。
- 项目空间增加即时搜索，名称、地点和项目 ID 均可匹配；已发布成果同步支持标题/项目检索。宽屏四列、较窄桌面三/两列、手机单列；入口改为完整蓝色按钮。
- 总览采用更清晰的判断卡与对象地图双栏，工作建议使用轻量城市插图。插图只作装饰，研究范围地图仍来自真实登记坐标。
- 地图搜索、筛选、选中对象卡与问答入口统一圆角与层级；修复隐藏地图信息栏造成其他页面问答入口偏移的旧选择器影响。
- 蓝色指示操作，绿色/橙色/红色分别保留完成、待核、实际异常语义，知识页继续采用中性底。
- 手机延续56px顶栏、按需导航、业务章节及逐条工作卡。390和320宽度默认内容区分别为788/512px，无整页纵向溢出；长文及工具仍按需打开。

本轮没有修改后台、接口、模型、规则或数据库。27项原有定向检查通过，导航测试补齐此前遗漏的matchMedia环境；生产构建与实际页面截图、发布回执存于research/test_results/reference-ui-*和output/playwright/reference-ui/。
