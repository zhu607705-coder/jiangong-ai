# 界面结构与页面归属

状态：已部署并完成实际页面验收。更新日期：2026-10-15。验收记录：`research/test_results/navigation-adaptation-browser-20261015.json`。

本轮按“全局工作区 → 项目工作页 → 二级工作区 → 局部详情”组织界面。下表是页面归属与旧入口迁移的当前约定；[前版结构稿](D:/海之子_界面逻辑结构稿.html)仅提供布局参考，其示例状态、数值和文字不作为项目结果。

## 全局工作区

| 页面 ID | 名称 | 归属内容 |
|---|---|---|
| `map` | 地图探索 | 搜索、选区、边界、空间对象与候选对象；进入选定项目的研究工作区。 |
| `projects` | 项目空间 | 项目列表、创建与切换、已保存或已发布成果入口。 |
| `knowledge` | 案例与规则 | 跨项目的案例、规则与成本参考维护；当前项目匹配结果归改造研判。 |

## 项目工作页

以下六页常驻导航，可直接访问和往返。表中的斜杠表示页面与二级工作区关系，不另定义一套 URL 参数。

| 页面 ID | 名称 | 二级工作区 | 主内容归属 |
|---|---|---|---|
| `overview` | 项目总览 | 页面摘要 | 项目范围、当前系统建议、人工工作方向、关键缺项、最近成果及下一步入口。 |
| `evidence` | 资料与条件 | `files` 资料与证据；`profile` 对象档案；`context` 项目经验与约束 | 内部资料询问、上传解析、原文与引用、对象条件和当前项目经验。 |
| `assessment` | 改造研判 | `direction` 改造方向判断；`current` 六维现况；`cases` 相关案例 | 真实 DSH 综合研判、模式与规则条件、当前六维评价、案例适用性。 |
| `scenarios` | 方案与测算 | `compare` 方案比选；`detail` 单方案工作区 | 候选方案横向比较、具体方案内容与测算。 |
| `actions` | 调查任务 | `current` 当前调查；`history` 历史记录 | 缺项、调查对象与回填要求、任务进度和已处理记录。 |
| `results` | 成果与版本 | `reports` 成果管理；`history` 版本变化 | 报告、结果快照和导出；首轮建议、补充材料、新决策及信息完备度的纵向对比。 |

`scenarios/detail` 内部再分 `content` 内容与效果、`funding` 建设与资金、`operations` 社区运营、`sensitivity` 敏感性与核验。运营核心按单方案同屏交互汇总，明细按需展开；方案采用的数量、资金与目标始终关联该方案及其资料基线。

## 兼容入口与详情层

| 旧入口 | 新归属 | 迁移含义 |
|---|---|---|
| `view=context` | `evidence/context` | 进入资料与条件下的项目经验与约束。 |
| `view=compare` | `results/history` | 进入成果与版本下的版本变化，继续查看原有决策版本对比。 |

旧 `view=compare` 与新的 `scenarios/compare` 含义不同：前者比较同一结果的前后版本，后者横向比较候选方案。迁移保留明确项目和已有定位信息。

运行阶段详情、模型与工具记录、局部原文证据使用抽屉。主页面保留当前结论、状态、关键冲突与必要操作；独立业务页和大型录入不收进运行详情。关闭抽屉后返回原项目、页面与方案位置。

## 行为与迁移约定

- 系统建议来自本次模型研究及程序条件核验；人工工作方向是使用者的工作选择，两者分别展示、保存，切换工作方向不改写系统建议或实施条件。
- 页面保持可自由访问。资料询问、补充与方向选择引导工作，缺项在对应位置展示，不把整个项目导航锁成逐步向导。
- 既有内部资料补充与上传解析迁入 `evidence/files`；真实 DSH 研判迁入 `assessment`；决策版本对比迁入 `results/history`；运营迁入单方案 `operations`。首轮基线、补充重研、原文与版本追溯继续保留。
- 本轮调整页面归属与呈现，复用原后端、六维计算和已有业务接口。校园部署实际验证了主页面、旧链接、单方案深链、原文抽屉和返回位置。地图入口可达，本次底图仍出现高德连接超时。

## 具体分项与内部数据

单方案内容先展示“优先序、具体对象与范围、改造做法、数量口径、交付效果、实施前提、出处与依据”。求是村当前资料 v14 已形成三项综合整治分项：29、30、31、48幢二次供水，75幢1单元加梯，高龄和空巢住户入户适老化。原文范围252户保留为范围数量；管线等未取得工程量按分项测量。

幸福度与满意度、电梯使用、实际到餐分别列采集方法、单位、时间窗、样本分母及影响的方案。就餐人数与用餐人次分别统计；无直接工程对应的采集请求保留项目层面入口。调查任务承接这些请求，取得资料后沿原上传与补充研判流程形成下一版，旧轮次继续保留。

同一项目资料版本的默认成果按原始生成时间选择较新结果，采纳旧成果的日期和接口返回先后不改写该选择。资料复核修订保留 `review` 元数据、原输出SHA及逐字段变化；模型原始输出与来源引文仍可回查。
