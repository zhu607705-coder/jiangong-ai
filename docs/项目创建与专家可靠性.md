# 项目创建与专家可靠性

地图选点没有返回地名时，研究名称先使用选点标签，可由使用者修改。创建窗口直接展示输入和网络错误；提交前核对项目输入并确认当前会话。沿用HTTP IP环境的安全UUID兼容实现，支持没有crypto.randomUUID、但具备crypto.getRandomValues的浏览器。

同一个窗口使用稳定草稿ID。服务端沿用Store和项目表，相同拥有者、ID及内容的重试返回原项目；内容不同或拥有者不同则返回冲突，不覆盖已有项目。创建成功后直接打开返回的项目快照，列表刷新独立进行。

专家研究前加载全部角色文件并检查输出契约、受限读取能力。原有小规模分工调用同时承担模型结构化输出的准备检查；调用失败时停止进入专家阶段。各任务按资料字符量和问题长度分配输出容量与研究时间，主研判保留150秒时间。不恢复模型调用次数或读取次数硬上限。

专家结果在本阶段检查。任务ID、引用范围、原句或已读窗口不一致时，利用同一受限工具和已读窗口立即修正。时间用尽或重复无变化的失败保留为未完成。取消信号同时约束工具读取和原生模型子任务。

原文完整保存在来源记录，主研判接收来源目录与真实原文窗口。专家观察中的重复引文改为quote_ref字符区间，原句在窗口保存一次；假设、前提、推理、参数范围与验证方法继续保留。压缩后逐项回读每条引文，任一引文丢失便停止进入最终综合。记录压缩前后字符量、保留引用数、专家输出验收尝试次数及分配容量；底层模型请求次数与用量取实际ModelCall记录。
