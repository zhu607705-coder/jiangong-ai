# 地图初筛与数据关联（2026-09-28）

本次把已有高德 3D 地图、真实项目数据库、已完成研究来源与 DSH 模型接在同一个选中卡片内。用户提供的截图和两份设计说明作为交互参考；截图中的价格、投资总分、趋势与项目数量不作为事实导入。没有更换地图引擎或另建一套研究调度器。

## 一次地图操作会发生什么

1. 点选地点：先反馈选中身份；汇集 800 米直线范围的地图记录，并按当前城市/点位关联项目资料。只读资料，不调用模型。
2. 一键标色：冻结点击时地图中心的 3×3 格网（最大经度跨度 0.018°、纬度跨度 0.014°），逐格返回进度。格网不是法定宗地。地图和资料查询都使用同一轮输入。
3. 切换专题：交通、商业生活、居住办公、文教医体、已定位项目；复用同一快照，不重新查询。固定数量阈值，同色不随本轮最大值变化；不同格网面积/时点仍不能当成可比密度。
4. 拖动地图：仅改变相机，保留候选范围；提示视野已变化。再次点击标色才重新确定范围。
5. 生成初判：用户明确点击后，DSH 对固定快照中的地图事实和项目公开资料作条件化分析；展示机会假设、反向解释、调查项及可跳转的来源引用。市级文件只作城市背景，元数据不能作为正文证据。模型推断仍需核验，不是批准。
6. 带入项目：公开地图快照和关联公开资料成为新项目来源；内部原文、事实和企业规则不通过这条公共来源路径转出。原有完整项目研究支持持久化运行、SSE、取消和恢复。

地图轻量初判切换对象时会取消过时请求。完整项目研究沿用已有持久化运行；不把前端临时等待冒充持久化任务。当前未实现设计稿中的完整多项目比较工作区或情景编辑器；已有的是项目内部候选路径比较。

## 数量、失败与模型的边界

使用高德 v3 返回的 `count` 作为提供方报告的匹配记录数，不把返回的 5 条样例当成全部数量。记录可能包含同一站点的多个出入口、子场所和重复实体。达到 600 条的结果被应用保守标为完整性待核，不参加数量分级；600 是本应用核验阈值，不声称是供应商公开保证的接口上限。失败是未知，成功返回的零条是另一状态。

地图证据的查询缓存通常为 10 分钟，来源失败短缓存 30 秒。项目版本更新重新关联证据并生成新快照，复用地图查询。一次扫描冻结项目版本；不会在中途因项目变化悄悄替换输入。

格网请求共享节流，默认至少间隔 500 毫秒；单来源 6 秒超时，扫描 60 秒预算。停止后传播 AbortSignal，停止后续查询；已发生的供应商调用不可保证撤销计费。已获取的部分资料保留，未完成不标成完成。

本机验证点（西湖文化广场附近，直线 800 米）：第一次资料返回 2.156 秒，缓存 0.009 秒；一次真实模型初判 4.12 秒且引用已有项目公开资料。一次浏览器九格采集约 22.454 秒。以上是单次样本，不是 p95/SLA。

## 代码与验收

- 地图与项目来源：`services/map-screening/`、`packages/maps/`。
- 宿主接口：`GET /api/maps/data`、`POST /api/maps/screening/context`、`POST /api/maps/screening/analysis`、`POST /api/maps/screening/scan`。继承本地会话、CSRF 与来源检查。
- 前端：`PreliminaryCard.tsx`、`ScreeningControls.tsx`、`DataSourcesPanel.tsx`。来源卡、筛选卡与主地图共用选中对象。
- 单一契约：JSON Schema → TypeScript/Pydantic。TypeScript 数组使用普通数组类型，长度约束仍由运行时 JSON Schema/Pydantic 执行。
- 回归证据：`research/test_results/screening-live.json`、`screening.json` 和对应日志。测试场景与真实供应商联调分开记录。

## UI 借鉴及范围

采用“地图发现 → 固定对象 → 查看证据 → 主动研究”的连续路径，而不是把不同产品的面板都放在首页。

- [Kepler.gl Interactions](https://docs.kepler.gl/docs/user-guides/g-interactions)：轻量 tooltip 与点击固定信息。这里保留点选侧栏和显式详情入口。
- [CARTO Widgets](https://docs.carto.com/carto-user-manual/maps/widgets)：区分 Global 与 Viewport 统计。本项目进一步将明确确认的筛选范围固定下来，不跟着相机移动改题。
- [ArcGIS Business Analyst Suitability](https://doc.arcgis.com/en/business-analyst/web/suitability-analysis.htm)：指标、图例和结果联动；当前证据不够支持加权投资总分，因此落地为可解释的单指标专题。
- [高德 POI 接口](https://lbs.amap.com/api/webservice/guide/api/search/)：提供周边/多边形检索、总数与分页样例；底图与统计依据由真实接口提供。
