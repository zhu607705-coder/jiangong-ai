# 公开资料持续采集与 AIHOT 沉淀

本轮把公开资料的持续采集接入已有 `IntelligenceService`、`intel_jobs`、原件版本库与 AIHOT 研读流程。目标为每日最多 1,000 次搜索尝试，均匀分布全天；不把搜索次数当作独立案例数。

## 费用与启用

2026-10-18 核对官方文档：独立 Search 和 Fetch 各为每千次成功、有结果请求 5 元。无结果、失败、超时不计接口费。Harness / Claude Code / Codex 的 Server 端搜索工具暂未计费，官方列明 2026-11-01 北京时间零点起计费；模型 token 费用另计。现有 DSH 官方搜索插件每次搜索仍需要一次模型调用。

来源：[官方 Search / Fetch 文档](https://api-docs.deepseek.com/zh-cn/guides/search/)、[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

持续采集采用已有独立 API 适配器，搜索默认请求正文，直接复用返回内容。默认配置为搜索 1,000 次、补取正文 200 次、每日接口费用预留上限 6 元；原有研读模型预算 40 次/日保持独立。默认暂停，须在明确日预算后由服务器设置 `INTELLIGENCE_CAMPAIGN_SPEND_APPROVED=true` 并启用采集。此开关只控制新增持续采集，不限制已有项目研究或资料整理。

## 覆盖与刷新

- 浙、沪、粤 18 城市、20 个主题、政府/交易/高校 3 类来源、近 7 年及不限年份，共 8,640 个可检查的主题组合。
- 主题包括预算、中标合同、结算审计、整治对象与户数、供排水、电梯、结构安全、安置出资、服务中心、社区食堂、满意度和全周期维护。
- 第一层优先广泛覆盖各城市和来源，再向历史年份扩展。同题至少间隔 7 天，已归档完整原文按真实取得时间 7 天复查。
- 检索城市仅为搜索条件；不会直接写成材料已经核实的项目所在地。城市仍由原文及现有研读结构提取。
- 官方附件或扫描件需要既有文件解析能力时保留未完成状态；不会把二进制 PDF 或搜索摘要标作完整正文。

## 存储与拆分

磁盘位置为 `${DATA_DIR}/corpus-public`，使用内容哈希和原件版本定位，不接受模型提供的文件路径。

```text
corpus-public/
  blobs/<sha256>.md                  # 去重后的正文
  blobs/<sha256>.raw.txt             # 采集器实际收到的正文表示（可能是 API Markdown）
  documents/<document-id>/<version>/
    original.md                     # 与入库正文完全相同，不额外插入标题
    source.json                     # 来源、正文哈希、版本、拆分政策
    chunks.jsonl                    # 原文行号、窗口起止、版本、原文片段
    raw.json                        # 实际有抓取表示时记录其哈希和 blob 路径
```

行拆分复用 `documentSlices`；长行窗口复用现有 `semanticWindows`，4,000 个 UTF-16 单元窗口、200 单元重叠。定位以 `line:N` 加行内起止表示，始终能回读到 `original.md`。文件中的原文和模型输出分开，不把摘要替换成原文。

原件、版本、全文索引、研读、事件/故事线继续使用原来的数据库。新增表仅记录采集设置、主题及检索发现、实际接口回执和磁盘档案索引。重复 URL 不增加独立原件数；同正文通过内容哈希复用 blob，转载仍保留各自 URL 与来源，不声称为独立证据。

## 执行与恢复

复用原有 5 秒工作器，不增加第二套调度器。每个采集任务只处理一个查询、最多 20 个结果；项目归集、RAG 索引和研读任务优先于批量采集。搜索与 Fetch 每次实际请求都先原子预留额度，重试也占本地次数。不确定的响应按 0.005 元预留，不能记成免费或自动重放。

公开原文先可检索和归档，复杂资料再进入已有 DSH / Decision 研读、结构提取、筛选与事件归并。自动研读保持最多 6 个未完成任务，服从原有 40 次模型日预算，避免为每个搜索命中排一次模型调用。模型提取和归并不会自动发布为项目事实或审核规则。

磁盘保留至少 5 GiB 空间；空间不足、认证失败、余额不足和持续失败会暂停或退避。暂停会停止正在执行的采集后续步骤，已取得原文保留。重启恢复队列，运行中断不冒充成功。

## 操作与核查

`案例与规则 → 资料沉淀` 展示日额度、实际尝试、费用预留、已落盘版本和可定位片段，可暂停/恢复和整理已有原文。

- `GET /api/intelligence/campaign`：设置、当日回执汇总与最近主题。
- `POST /api/intelligence/campaign`：启停和日额度。未获费用授权时不能启动新增持续调用。
- `POST /api/intelligence/campaign/snapshot`：把已有公开版本补存为 Markdown/JSON/片段，不调用搜索或模型。

验证分别记录离线额度/隐私/恢复契约、构建、服务器归档与页面回读。千次持续搜索的实际召回率、每日净新增案例量和原生成本，在费用确认并运行后按真实回执评估。
