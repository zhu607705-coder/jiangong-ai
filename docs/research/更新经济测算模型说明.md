# 住区更新方式比较：离线经济测算原型

本模型将“改造方式”表达为任意 `mode_id` 与措施组件列表。同一范围可以比较保留整治、局部拆建、整体拆建、增设设施、功能置换、经营运营及其分期组合。先记录各模式的硬条件，再分别核算收益、支出、资金和居民负担，不设一种固定的综合权重来替代模式选择。

## 四账与主体

每个模式登记 `cash_subject`，按该主体计算收支；其他主体的支出或收入单列排除原因。成本账保存建设、安置、运维等费用；现金收入账保存具备归属、用途与处分或收费权限的对外销售、出租、服务收入；资金安排账保存居民分摊、财政补助、贷款及本息偿付；资产效益账保存归属于居民等主体的物业估值变化。居民增面积付款进入资金分担，对外销售进入现金收入，以经济事项 ID 防止重复。房产增值不加入现金净现值。

输入数值保存单位、时点、来源及 `factual/reference/assumption/missing` 状态；行记录受益人、付款人或收款人、起止年。销售面积与单价、出租面积与租金使用匹配口径，并登记城市、用途、税费口径和价格时点。贷款须关联期内还本息行。金额统一为元，面积为平方米，出租率和折现率为小数比例。

## 可核算输出

设年度成本为 \(C_t\)，有权现金收入为 \(R_t\)，折现率为 \(r\)，测算期为 \(T\)。

- 静态现金收支：\(\sum_{t=0}^{T}(R_t-C_t)\)。
- 经营净现值：\(NPV=\sum_{t=0}^{T}(R_t-C_t)/(1+r)^t\)，不加入出资、贷款或资产增值。
- 年度维护余额：当年租赁及服务收入减当年维护费用；维护覆盖倍数为前者除以后者，无维护支出的年度保留空值。
- 峰值资金缺口：以期初可支配资金为起点，逐年累加现金收支、出资和贷款，扣除本息及返还；最低累计余额的负值即需补齐的峰值资金。计划安排与已确认可用安排分算。
- 保本售价或租金：固定其他收入、费用和时序，将目标收入的单位价格作为未知数解 \(NPV=0\)。出租按“可出租面积×12×出租率×月单价”核算。
- 居民预算匹配：分别比较家庭月支出与月预算、一次性缴款与一次性预算，保留超出金额。

年度金额使用 `Decimal`，仅在结果显示时保留到分。当前按年度末折现，同年出资和工程付款归一个年度桶；没有加入自动售罄率、房价涨幅、期末残值或默认运维增长。若需要这些因素，直接新增明确费用、收入或资产行。

## 条件与输出依据

已确认硬冲突只暂缓对应模式；其余模式仍可比较。核心费用、收入权利、市场价格、居民预算或资金使用条件缺项时，输出 **“先补充关键资料再判断”**，受影响合计及指标为 `null`。可选收入缺项在明确基线且其他核心数据齐备时列入“条件机会”，基线收益表明其剔除范围，不把未知收入写成实际零收益。资料齐备后输出“建议开展专项调查”，同时列出 NPV、资金缺口、维护覆盖和预算匹配的规则依据；负净现值或支付超预算直接展示对应金额，供专业人员调整路径。

规则编号：`ECON-COST` 费用范围，`ECON-REALIZABLE` 有权收益，`ECON-FUNDING` 出资可用性，`ECON-DEBT` 本息时序，`ECON-NPV` 净现值，`ECON-CASH-GAP` 现金缺口，`ECON-MAINTENANCE` 运维覆盖，`ECON-AFFORD` 可负担性。硬规则编号由输入登记。程序输出保留完整输入快照，便于逐项追溯。

## 运行与演示结果

```powershell
python -m unittest discover -s tests -p test_renewal_economics.py -v
python scripts/compare-renewal-modes.py data/templates/renewal-mode-input.example.json --output output/renewal-mode-demo.json
```

示例中的全部数字标为“演示假设”，不对应求是村、浙工新村或上海案例。五年、5% 折现率下：保留整治加服务运营的现金 NPV 为 56,392.31 元，峰值资金缺口为 0，保本月租为 115.18 元/平方米；部分保留、局部拆建与经营组合的 NPV 为 -285,683.11 元，峰值资金缺口为 1,000,000 元；整体拆建方案因处分权限和销售单价缺项输出“先补充关键资料再判断”，NPV 与完整资金缺口保持空值。

已通过十项回归，覆盖关键金额、四账隔离、增面积处分权限、重复记账、未知传播、条件机会、混合模式、模式局部硬冲突、居民预算和价格/费用/折现率敏感性。此原型复用了现有 `calculateRetrofitPlan` 的未知值及缺口口径，将现金流分账与时序独立补为标准库 Python 工具；没有修改工作台接口、数据库和 Agent。城市间价格、费用与权利条件可逐项替换，不直接把上海金额搬到杭州。
