# 求是村
## 更新决策研判报告与改造方案

研究日期：2026-10-15。版本：QS-R20261015。研究对象为杭州市西湖区灵隐街道浙大求是社区内的求是村住宅区；社区级统计、具体楼幢和工程包分别记账。本报告由公开资料调研、工作台原文定位、既有真实 Agent 方案记录及历史工程对标形成，用于确定更新方向、投入顺序与调查任务。

## 1. 决策摘要：保留整治优先，按对象解决问题

**总体方案：以既有设施后评估、未覆盖对象补缺和连续适老通行为起点，优先研究保留建筑的综合整治；服务运营与维护安排同步设计。对确需拆建的个别楼幢，取得逐栋鉴定后另设专项比较，不将局部问题推为全片拆除。**

| 核心问题 | 本轮判断 | 对应决策 |
|---|---|---|
| 要不要更新？ | 有必要继续改善。供水、加梯和邻里中心已有不同阶段投入，下一轮应针对未覆盖人群、使用障碍和跨系统接口。 | 启动楼幢、设施、服务与责任核查；保留已有效投入，避免重复建设。 |
| 值不值得投？ | 优先将前期资源投入可明确对象、工程量和维护主体的整治子包。整片重建尚不具备可比较的技术、权属、安置和资金条件。 | 先形成轻档核查及小范围改善任务书，再根据调查结果选择中档整治或局部重建专项。 |
| 投下去产生什么收益？ | 首要收益是更连续的出行、更可靠的设施与可持续公共服务；经营收入、财政支出和居民资产变化分别评价。 | 比较四账：建设资本、财政负担、运营财务、社会效果；运营补贴列财政支出，不列政府收益。 |

当前可作出的决定是**开展有对象的专项调查与方案深化**。施工范围、专项投资控制数及拆建对象由下一阶段的鉴定、工程量、权属规划、决议和资金材料共同确定。发生危及安全的现场情况时，先由责任主体采取必要措施并组织专业处置，不等待本研究的方案排序。

### 本轮先落实的六项工作

1. 对29、30、31、48幢供水工程逐幢追踪施工、验收和接管，辨认已完成与仍需改造的内容。
2. 将留博楼单列，核对当年泵房位置排除原因及后续技术方案。
3. 对已加梯、正在审批和仍在协调的单元分组建账，检查电梯到户门、出入口和邻里中心的连续通行。
4. 使用既有邻里中心，先改服务时段、到达路径与服务覆盖，再论证新增空间。
5. 将管网、路面、消防、充电和照护短停的接口统一画在问题图上，条件允许时合并施工窗口。
6. 每项工程在定方案时同时明确接收、检验、维保、费用和交接，形成建设与长期责任闭环。

## 3. 改造模式前置判定

### 3.1 先核必要条件，再比较收益

| 条件组 | 保留整治要回答什么 | 拆除重建另需回答什么 |
|---|---|---|
| 结构与工程适用 | 房屋是否适修；供水、消防、通行等问题能否通过修缮和组织改善解决。 | 哪些具体楼幢存在修缮难以解决的问题；拆建相对修缮的技术必要性。 |
| 权属与规划 | 谁能决定施工及使用共有部位；管线、土地、学校资产接口如何落实。 | 宗地、产权处置、规划条件、保护要求及重建规模是否有书面依据。 |
| 居民决策与过渡 | 受影响业主与实际使用者分别是谁；施工期间如何保障用水和出行。 | 适用决议程序、出资承受力、腾退、临时安置、回搬和抵押处理。 |
| 全口径资金 | 工程量、建设资金和后续维护是否匹配。 | 拆除、新建、迁改、安置过渡、融资及长期费用能否覆盖，出资是否落实。 |
| 交付与维护 | 谁验收、接收、救援、维保及承担大修。 | 重建后的产权交付、设施接收、物业服务及长期缴费机制。 |

**本轮模式结论：保留整治是优先深化方向；局部拆建是条件化研究备选。** 现有公开材料能解释设施改善和协商经验，尚不能支持整片住宅拆除。房龄较老、某类设施缺失或其他小区曾有C级危房，都不能单独确定求是村应拆建；具体安全处置依据本项目逐栋专业结论。

### 3.2 模型负责解释，程序负责判定

工作台在10月14日对求是村资料生成了真实 DeepSeek Flash 总体方案，提出综合整治与条件化拆建两条路径。本报告采用其“先逐栋建档、核对已实施项目、分项登记居民意见”的组织思路，并将供水报道明确回写为2023年计划阶段。模型提出的目标是方案内容，实际完成状态由验收、合同和现场资料确认。

程序检查来源、逐字引文、对象时点、金额单位和必要条件；证据不足时生成调查任务，不把模型偏好写成确定性拆建结论。权重可以表达“先改善出行”或“先控制财政负担”等比较偏好，但不能改变原文事实或抵消已确认的安全、权属和保护约束。

方案比较先排除不满足必要条件的候选，再在可行候选间观察投资、可支付性、服务改善和维护压力。存在取舍时展示各项差异及权重敏感性，不以一个总分遮蔽损益。



## 4. 六维现况与改后目标

六维评价回答“现有依据说明了什么、拟改变什么、怎样验收”。本轮以可观察内容呈现现况，不将资料覆盖程度换成工程质量分，也不填写未经量测的雷达图分值。

| 维度 | 有依据的现况判断 | 对应方案目标与核验方式 |
|---|---|---|
| 居民需求 | 加梯及适老服务已有个案和协商记录，需求存在楼层、身体状况和家庭照护差异。尚缺分户需求及出资承受力基线。 | 建立分楼幢、楼层、实际使用人和权利主体的需求表；分别记录受益、受扰与反对理由，以重复陪访和需求解决清单复查。 |
| 公共服务 | 邻里中心已启用，是本轮可复用资产；开放、付费、使用和不能到场人群仍需台账。[H11](https://xhb.xihunet.cn/h5/html5/2025-10/28/content_9248_18995526.htm) | 打通户门至中心及照护接送点的连续路径；比较时段调整、预约、配送、接驳与增建设施的必要性。 |
| 居住工程 | 已有加梯、二供安排与充电设施；供水原文指向当时设备和管道问题，不能代表所有楼幢当前状况。 | 逐设施确定保留、维修、改造或检测；四幢供水补齐阶段链，留博楼独立论证；按图纸、检验和工单确认效果。 |
| 实施协同 | “求是有约”等议事经验与单元征求程序已有记录。不同产权和具体工程仍需对应当前有权主体。 | 形成资产所有者、决定人、实施人、验收人和维护人的责任表；逐议题回应异议，保存设计调整及适用决议材料。 |
| 长效维护 | 电梯托管提供已有组织基础，报道月费不等于现在的全部运行成本。[H08](https://zjnews.zjol.com.cn/zjnews/202312/t20231228_26545272.shtml) | 核定托管、维保、检验、救援、保险及大修边界；用停运、维修闭合和交接清单复查。 |
| 资金交付 | 分项工程持续推进，但尚未形成与本轮范围对应的完整工程量、资金落实和长期账。 | 每个工程包都有清单、同口径价格、资金主体和缺口；交付后对照合同、结算、资产接收和年度运营支出。 |

### 六维目标怎样变成可交付的变化

连续适老路径的目标不是“公共服务提高1分”，而是明确一条从住户到电梯、出入口、服务中心的路线，记录断点、责任和措施；实施后在相同路线与使用条件下复查。二供目标是四幢分别取得验收接管记录、留博楼形成有依据的技术处理决定。长效维护目标则是每项新增或保留设施均能找到当前接收主体、服务合同和费用渠道。

## 6. 轻、中、重三档范围与进入条件

三档用于比较投入范围，工程数量以第5节清单和现场量测确定。基础档不替代必要的安全专业处置；重档也不意味着必须全片重建。

| 档位 | 范围及主要投入 | 进入条件与预期作用 |
|---|---|---|
| 轻档：核查、运行优化及小范围改善 | 档案建账、专业检测、陪访、维护合同整理；在技术和权利条件明确处开展照明、防滑、扶手、标识或时段调整等小项目。 | 对象和费用边界明确；首先减少现有设施使用障碍、重复投入与责任空档。 |
| 中档：分期综合整治 | 在轻档发现的明确问题上，组合供水、排水、消防、通行、加梯接口与必要公共空间工程；保留状态良好的设施。 | 图纸、工程量、技术、决议和接收主体明确；资金覆盖本期工程及维护。减少重复施工，补齐关键功能。 |
| 重档：局部拆建专项比较 | 仅对有必要性依据的具体楼幢比较修缮与拆建；计入拆除、新建、迁改、安置过渡、融资和后续设施服务。 | 逐栋鉴定、权属规划、居民决定、安置和资金条件齐备，才进入项目论证；解释拆建是否比整治更合适。 |

### 6.1 投资计算方法

**轻档投入 C轻＝调查建账＋专业检测与设计＋明确小项目工程量×同口径单价＋本档适用的其他费用。**

**中档投入 C中＝本期各子包工程量×相应单价＋设计检测＋迁改和临时保障＋按具体计取基数确定的其他费用及预备安排。** 已由前期完成的相同内容从本期扣除；跨包共同工程只计一次。

**重档投入 C重＝拆除＋新建＋迁改＋腾退安置与过渡＋专业及法定费用＋财务费用＋明确基数的预备安排。** 与修缮路径使用同一研究范围、价格时点和比较期限；既有设施残值或沉没投入单列说明。

当前缺少求是村完整面积、管线长度、需改数量及本地清单报价，因此本报告给出可使用的计价结构与原件参考。第一阶段交付补齐各档工程量和同口径单价，形成可复算投资表。

## 7. 投资与收益：四本账分别回答谁投入、谁受益

| 账目 | 核算内容 | 供决策比较的结果 |
|---|---|---|
| 建设资本账 | 工程、专业服务、迁改、安置及适用其他费用；列产权人、居民、财政和其他出资；区分承诺、申请与到账。 | 总投入、分期支出、已落实资金、未落实缺口、各主体支付压力。 |
| 财政账 | 财政资本投入、购买服务、运营补贴及直接支出；实际有依据的政府回款另列。 | 年度和全期财政净负担，每单位新增服务或改善对象对应财政支出。 |
| 运营财务账 | 收费与经营收入、购买服务和补贴，分别扣人工、耗材、能耗、维保、保险及应承担的其他费用。 | 不含补贴的经营余缺、含支持后的现金余缺、收支平衡所需服务量及支持条件。 |
| 社会效果账 | 独立服务人数与人次、重点人群覆盖、空间时段利用、通行障碍、停运、投诉及维护响应。 | 哪些居民受益、改善多少、需求是否满足、费用和空间分配是否产生不利影响。 |

居民房屋的可能增值属于居民资产效果；只有发生且合法可实现的交易收入才进入相应主体现金流。运营补贴是财政支出和运营方资金来源，在跨主体合并经济分析中属于转移支付，不能重复记为新增社会收益。

### 7.1 资金与经营计算

**建设未落实缺口＝本期资本投入－已确认可用于该期的财政、产权人、居民及其他资金。** 申请中的补助另列阶段、支付时间和垫资主体，不当作开工现金。

**不含补贴的运营余缺＝实际收费和经营收入＋对应已交付服务的购买服务收入－同期间运营现金支出。**

**含支持后的运营余缺＝不含补贴的运营余缺＋运营补贴。** 购买服务给出购买数量和交付标准，与无对应服务数量的补贴分开。设备折旧及未来大修储备另列，使短期现金结余和长期成本得到对应。

**财政净负担＝资本投入＋购买服务＋补贴＋其他直接支出－可核实政府回款。** 未取得求是村回款依据时不填政府收益。亏损运营并不自动意味着无公共价值，关键是提供何种服务、覆盖谁、单位财政投入是否合理且可持续。

多年度方案保存年度现金流、价格口径、比较期限和折现假设，分别比较资本及维护支出、财务可持续性；公共服务效果先以实物指标报告。有独立估值依据时才补充货币化。

### 7.2 审批对照表如何形成

轻、中、重档使用同一对象清单及价格时点，逐项比较“多花在哪里、增加哪些受益、增加哪些长期责任”。比较权重由负责专业人员说明含义和版本；给出不同权重下排序是否变化、哪一项最影响选择。对尚无量测的指标先用文字与取证任务，采集后进入数值比较。

月度运营结果安排在整体模式与工程方案之后。先明确邻里中心的真实场地、服务和人员，再比较场次、时段、预约和支持资金；服务人次与独立人数分别记录，防止重复到访导致覆盖率虚高。

### 触发规则

1. **适修且关键条件明确：** 深化保留整治；比较不同措施的全周期投入、居民影响与维护。
2. **具体楼幢修缮难以解决关键问题：** 增加该楼幢拆建专项，联核技术、产权规划、决议安置与资金。
3. **关键条件未知：** 建立有对象、持有人、取得方式和完成标准的调查任务，保留条件化方案。
4. **某候选存在已核实否决条件：** 调整或停止该候选，不以高收益或满意度覆盖。
5. **资金不足但可以分期：** 说明先做范围及剩余需求，保证本期独立可用并落实维护。



## 11. 30天启动与后续实施计划

第1—30天是建议的研究启动窗口，以实际资料取得、专业资源和合法访问安排调整。工程开工、拆建及采购另按适用程序确定。

| 阶段 | 工作与协调接口 | 阶段验收产物 |
|---|---|---|
| 第1—3天：对象对齐 | 社区牵头，物业和业主组织提供清册；学校对实际校产或委托事项确认。 | 楼幢—单元—产权—管理区域清册；资料持有人；调查对象版本。 |
| 第4—10天：原件与现场 | 核四幢供水、留博楼、加梯队列和邻里中心；路线陪访、分群需求与异议登记。 | 工程阶段链、问题图、设施可用及受益受扰清单。 |
| 第11—17天：专业与价格 | 组织针对性安全、供水、消防和无障碍核查；细化工程量，核资金与合同。 | 候选必要条件表、专业意见、同口径价格组、维护及资金责任。 |

| 后续设计及实施 | 以任务书组织设计、预算、决策、采购与施工；统筹管网及路面窗口。 | 图纸、清单、合同、变更、验收和接管，逐项关联举措。 |

## 12. 后评估：观察实际收益，而不只数新增设备

|---|---|---|

实施前采基线，试运行核交付，稳定后按月复查。观察数量较少时公布分子、分母和时间；有条件再增加可比较对象，逐步开展完整的前后及对照评价。

社区中心不以营收单一考核。重点观察能否覆盖难以到场的居民、空间是否持续使用、单位财政投入交付什么服务、维护能否延续。



## 13. 报告、证据与工作台版本联动
