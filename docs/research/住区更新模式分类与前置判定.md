# 住区更新模式分类与前置判定

研究日期：2026-10-12。本文供模式目录、数据表和专家规则设计使用；对应模板为 `data/templates/renewal-mode-catalog.json`。

## 分类结论

住区更新宜按“建筑与空间怎么改、谁来组织、钱从哪里来、建成后谁运营”分别记录。物理方式分为七个家族：保留综合整治、结构加固与专项修缮、成套化与适度改扩建、局部拆建与保留、整体拆除重建、保护性修缮与适应性利用、功能置换与服务设施植入。自主更新体现业主组织和出资，EPC体现工程交付，融资贷款体现资金安排，均可与多种物理方式组合。依据：杭州正式意见二（二）、四（三）（S3）；浙江试点意见一、二（S4）。

一个小区可以按栋、单元、公共空间分别选方式。例如，部分楼栋保留加固并改善厨卫，危旧楼栋在鉴定、规划和居民协商成立后局部重建，闲置用房植入养老服务，公共管线统一更新，电梯再叠加维护托管。比较单位应是包含工程、过渡安置、服务与维护安排的完整方案包，避免把单项修缮和含地下车库的整体重建直接按总价排序。国家2025年意见二（一）将加固、改建、重建并列，二（二）、（三）支持整治与完整社区建设，杭州意见允许对部分或全部房屋依法拆建。（S1、S3）

模式前置首先采集逐栋结构鉴定与适修性、保护名录及控制范围、土地和房屋权属、规划边界和许可路径、业主表决对象与意见、现有及拟增面积、临时安置需求。结构具备加固价值时比较保留与加固；独立厨卫、户型和垂直交通短缺且有空间和审批路径时增加成套化与改扩建；问题集中于少数楼栋时比较局部拆建；整体质量和功能问题广泛时研究整体重建。保护对象按保护要求组织修缮和合理利用。现有闲置空间、服务缺口与运营需求相遇时，加入功能置换和设施植入。（S1、S3、S5）

随后比较市场需求、支付能力、合法可处置空间、建设和过渡成本、分主体现金流与年度维护缺口。造血渠道包括有明确经营权益的服务空间出租、停车和服务经营，节能与统筹维护形成的成本节约，以及经认定的新增空间处置或移交抵成本；居民和产权单位分担归入资金筹措。新增面积先区分居民扩面、安置、保障住房、公共服务和获准市场化处置面积，再选收益路径。浙江试点意见三（一）明确特定新增面积可移交政府冲抵成本，上海办法第十四条明确增量房源的安置和保障性用途。（S4、S5）

必要条件缺项时，对受影响模式输出“先补充关键资料再判断”，附核实对象、采集方式和需重算的判断。某项选配服务收益没有数据时，保留原方案，暂不计该项收益，并单列补充调查；如果方案必须依靠它才能平衡资金，就把它升级为该方案的必要条件。关键规则由专家按地区、对象和阶段审核；地区间迁移的是判断结构和措施经验，规划条件、同意率、成本和收益使用项目所在地资料。（S3、S4、S5）

## 七类物理方式与可叠加组件

| 编号、物理方式 | 可比较的对象与条件 | 增补采集内容 | 经营与资金组件 |
|---|---|---|---|
| M01 保留综合整治 | 主体可继续使用，问题以管线、环境、公共部位和设施为主 | 设施检测、工程量、覆盖对象、施工影响、移交责任 | 停车/充电等获准经营；产权单位和专营单位分担；年度维护安排 |
| M02 结构加固与专项修缮 | 鉴定发现安全问题且存在加固、维修路径 | 结构鉴定、适修性、加固设计、施工期间居住安排、修缮周期 | 节能与耐久性带来的支出节约；维修资金及责任主体分担 |
| M03 成套化与适度改扩建 | 厨卫、户型、交通等功能短缺，保留建筑可改建或扩建 | 实测户型、扩面需求、结构承载、日照消防、拟增面积和用途、许可 | 按权益和批准用途选择居民扩面付费、政府接收抵成本或出租 |
| M04 局部拆建与保留 | 安全问题、功能短缺或土地条件分布不均 | 逐栋分区、拆建边界、保留楼受影响、分期过渡、管网联动 | 分期投入；合法新增空间/服务空间处置；共同设施费用分担 |
| M05 整体拆除重建 | 范围内住房质量与功能问题广泛，已明确拆建审查、权属和安置路径 | 鉴定、设计与容量、套数和面积台账、安置周期、回迁权益、全成本 | 业主和单位分担；经认定的增量用途与接收价；完整交付及运维预算 |
| M06 保护性修缮与适应性利用 | 文物、历史建筑、保护街区或其他保护对象 | 名录与保护边界、修缮方案、保护审批、允许用途、使用容量 | 符合保护要求的使用和出租、服务经营、维护基金 |
| M07 功能置换与服务设施植入 | 存量空间与公共服务/住房功能需求可衔接 | 空间权属、用途转换、消防条件、客群和支付能力、合同与运营测算 | 服务用房租赁、养老托育等经营、保障性住房运营、采购服务 |

服务运营更新、加装电梯、无障碍、节能、地下空间利用和分期安置作为组件叠加；其中前三者可以只作用于一栋楼、一个设施或一组家庭。实施主体、财政补助、居民自筹、单位分担、借款融资和建设代理分别设字段，方案生成时组合。

## 对应系统规则与采集方式

以下是待专家审核的规则设计，目录中的 `review_status` 为 `proposed_expert_review`，尚未写入生产规则库。

| 规则 | 正向条件与判断动作 | 来源类型、采集方式 |
|---|---|---|
| MODE-G01 安全与适修性 | 按专业鉴定、加固价值和技术路线生成保留/加固/改建/重建候选；危险住房同时记录即时安全处置任务 | 公开排查名录/获准鉴定原件；住建与产权人访谈、委托检测 |
| MODE-G02 保护与权属 | 对照保护清单、权属证和用地红线，把允许改变的结构、用途和边界写入方案 | 公开名录与规划/权属原件；政府目录核验、档案调阅 |
| MODE-G03 规划与面积用途 | 明确增建范围、每类面积用途、审批路径及计容口径后，再进入面积处置或运营收入计算 | 公开控规/项目批复；规划部门访谈、测绘、方案核定 |
| MODE-G04 意愿与安置 | 分开记录初步意愿、正式表决与签约；以本地适用制度和项目批准条件组织下一阶段 | 问卷/访谈/合法表决与协议；按户与权利人台账采集 |
| MODE-G05 收支与支付 | 成本分摊、各主体支付能力、经营收入权利和资金安排共同形成资金平衡情景 | 公开项目数据/居民问卷/机构报价与访谈；分项测算、同区域可比样本 |
| MODE-G06 长效运营 | 明确设施接收主体、维护合同与年支出，加入可落实的经营收益和成本节约 | 合同与公开预算/运营访谈；合同条款抽取、运维台账 |
| MODE-G07 缺项分流 | 必要未知→受影响模式待补充；选配收益未知→该收益不计入，继续比较已有方案；已核实障碍→列出受影响模式及调整路径 | 所有资料；逐字段标记 known/missing/unavailable/conflict，保存核实任务 |

数据表建议保持“前置模式判定 + 原六维 + 市场收益”的结构。其中资金交付记录来源、支付与结算，市场收益记录价格、租金、服务经营、目标人群、支付能力和现金流归属，两者通过同一方案版本关联。
