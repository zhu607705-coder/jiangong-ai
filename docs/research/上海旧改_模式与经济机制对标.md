# 上海旧住房更新：模式与经济机制对标

研究日期：2026-10-12。用途：为杭州老旧小区更新的模式比较、经济测算和案例库提供可核对的上海经验。主案例分别为彭一小区、曹杨一村、曹杨八村75—76号，覆盖整体拆除重建、历史住区保护更新、单幢混合成套改造。数字、时点、资料位置与缺项保存在配套 JSON。

## 1. 模式比较应分成三条轴

上海官方材料已经呈现“拆、扩、抽、加”以及功能置换、申请式腾退等路径。建议把物理改造、实施组织、资金经营拆开，再组合候选方案：

| 轴线 | 可组合选项 | 前置调查 |
|---|---|---|
| 物理与空间措施 | 综合修缮、结构加固、厨卫成套化、贴扩建、加层、抽户降密、局部原址改建、整体拆除重建、功能置换 | 安全鉴定、保护等级、房屋间距、消防与日照、规划容量、基础与管线 |
| 权利与实施组织 | 政府统筹、公房调整、居民自主更新、承租权归集、协议置换、申请式腾退 | 权利人名册、用地边界、产权及承租关系、居民选择、方案与协议 |
| 资金与长期经营 | 财政投入、居民出资、专项债、租赁住房经营、社区服务或停车经营、跨项目统筹 | 可经营资产和使用权、价格与支付能力、审批路径、投入与过渡费、维护责任、债务偿付 |

这些选项可以在不同楼栋、分期和资产上混合采用。模型应先判定技术与权利可行性，再比较居民得益、全周期现金流和资金缺口。[上海市房管局2025年提案答复](https://www.shanghai.gov.cn/gwk/search/content/1c9b99697c324050b5d4f47bfc637f73)、[上海新闻办：改造方式与资金路径](https://en.shio.gov.cn/TrueCMS/shxwbgs/ywts/content/c235c900-c155-4ff6-a785-9714debc8642.htm)

## 2. 彭一小区：整体拆除重建与差异化权益安排

### 已有事实

静安区彭一小区2025年6月启动回搬：原40幢旧住房更新为17幢高层电梯住宅，涉及2110户；配套1600个车位和社区服务设施。原有权利结构包括362户产权房，其余存在租赁房；原始房型282种。产权房方案增加约20平方米建筑面积，增量费用由政府承担80%；租赁房报道记载使用面积增约2平方米，连同独用厨卫与阳台的套内总增量为14—17平方米。政府还收储并统筹了周边独立地块。[市政府回搬报道](https://www.shanghai.gov.cn/nw4411/20250629/122d68440df64622856c021d406fbbc7.html?siteId=1)、[市住建委权益安排报道](https://zjw.sh.gov.cn/gqdt/20250630/5851d22372be48108cd6e72ee46b4dbd.html)

### 案例拆分

1. `PENG1-A01`：整体拆除重建。关联旧楼、结构和居住功能、新楼及车位、搬迁过渡、公共服务。
2. `PENG1-A02`：产权房增量安排。关联产权户、增加建筑面积、政府补贴比例、住户负担、分配规则。
3. `PENG1-A03`：租赁房成套化与权益调整。保留使用面积和套内总增量两种指标，关联承租合同与回搬方案。
4. `PENG1-A04`：宗地整合及公共服务植入。关联规划地块、设施产权、经营与维护主体。

### 对标方案、优势与当前建议

**方案**：对技术鉴定、规划容量和权利协商支持整体更新的对象，建立“整体重建＋差异化回搬＋公共服务补齐”候选方案。**优势**：一次解决非成套住房、垂直交通和配套空间问题，并通过不同权利类型的安排推进协商。**当前建议**：杭州同类对象进入重建可行性专项调查，先列明回搬需求、可经营空间、建设与过渡费用；产权房和承租房分别测算。案例整体投入、过渡补助、租金和维护费为缺项。

## 3. 曹杨一村：风貌保护、结构加固与功能成套化

### 已有事实

曹杨一村为优秀历史建筑。2025年市住建委材料记载保护修缮范围48幢、1499户、2400人、4.89万平方米；2022年街道回搬总结记载48个自然幢、67个门牌幢、约1500户。改造保留总平面与南立面，进行北侧局部贴扩建、结构加固和楼梯调整，增加独立厨卫；普陀区规划资源局记载户均使用面积增加约8平方米。2021年底施工和交房回搬总体完成。[范围与保护措施](https://zjw.sh.gov.cn/gqdt/20251217/cb50bb7da9164cd8a69ed06dd5a5c379.html)、[面积及设计机制](https://www.shpt.gov.cn/gtj-zfbm/tpxinwen-gtj/20251126/965414.html)、[交房回搬](https://www.shpt.gov.cn/cyjd-jiedaozhen/alcy-cyjd/20220218/834027.html)

### 案例拆分

1. `CAOYANG1-A01`：南立面与历史肌理保护；关联保护部位和审批方案。
2. `CAOYANG1-A02`：结构加固与楼板更新；关联检测、工程量和抗震方案。
3. `CAOYANG1-A03`：北侧贴扩建、厨卫成套化；关联住户、面积增量、管线与消防。
4. `CAOYANG1-A04`：楼梯调整与居民参与设计；关联老年人出行、设计图、意见及最终选择。

### 对标方案、优势与当前建议

**方案**：以楼栋为单位比较“保护修缮＋结构加固＋局部贴扩建＋厨卫成套化”，结合设施和通行改善。**优势**：在延续原有街坊空间、居民网络和历史风貌的同时解决生活功能问题。**当前建议**：杭州有保护价值或可保留建筑优先建立这一候选组合，并征集施工、过渡和维护报价。建筑增量用途记录为居民厨卫；可经营资产、租售价格、总投入和居民支付为缺项，进入专项采集清单。

## 4. 曹杨八村75—76号：同一栋房屋内组合多种改造动作

### 已有事实

普陀区发改委2025年1月20日项目建议书批复同时采用贴扩建、内部分隔和原址改建，涉及1幢、76户；建筑面积约2266平方米增至3072平方米。投资匡算2901万元，其中建安2378万元、工程建设其他费385万元、预备费138万元，所需资金由区财政统筹。前期费在可研阶段明确。2026年度资金申请为556万元；该数字另列为年度预算。2026年又延续规划土地意见书和设计方案批复有效期。[立项及成本](https://www.shpt.gov.cn/zhengwu/xmjyssp-fgwzdgz/2025/42/194395.html)、[年度绩效目标，PDF第27页](https://www.shpt.gov.cn/zhengwu/jxpj-czzj/2026/37/201586/fc5eaffcdf4148fdbd4cdd7d931c056b.pdf)、[土地意见书延期](https://www.shpt.gov.cn/zhengwu/yslztz-ghzyjzdgz/2026/23/201338.html)、[设计方案延期，PDF第2页](https://www.shpt.gov.cn/zhengwu/jsgcsjfascyj-ghzyjzdgz/2026/107/203278/18e7d017497049799af82794390c8f39.pdf)

### 案例拆分与计算

分别建立 `CAOYANG8-A01`贴扩建、`A02`内部分隔、`A03`局部原址改建、`A04`财政资金与年度交付卡；2901万元挂在整体项目，分措施金额为缺项。

由批复数据计算：面积增量806平方米，增幅35.57%；整体匡算户均38.17万元，按改后面积摊算约9443元/平方米，其中建安约7741元/平方米。计算基准均为2025年批复，成本阶段为匡算。经营面积的用途、权属和收入为缺项。

### 对标方案、优势与当前建议

**方案**：按单元和局部构件选择保留、改建或扩建措施，建立同一楼栋内的混合改造方案。**优势**：避免以一个小区统一标签替代各楼栋差异，能够保留可用部分、集中解决特定功能问题。**当前建议**：作为混合模式的计算样例，杭州方案重新取得设计、鉴定和本地分项报价；阶段展示为“已立项、有年度目标与审批续期记录”，回搬和竣工资料进入后续采集任务。

## 5. 造血机制如何进入研判

上海房管局2025年答复提出承租权归集、自有物权自主更新和长周期金融支持；上海新闻办材料介绍增量保租房与周边经营性设施统筹。分别建立三本账：

- **项目现金流**：居民出资、财政与补助、经批准的出售收入、租赁和经营净收入；扣除建设、过渡、融资、税费和长期维护支出。
- **居民账**：支付能力、面积与功能改善、租金负担、搬迁影响、维护分摊、退出与回搬权益。
- **公共价值账**：安全、可达性、服务容量、风貌与社区联系；没有价格参数时保留分项实物指标。

模型中的出租面积、可售面积、运营期限和租售价须有资产与审批记录；对未采得字段保存 `null` 与 `missing`。可识别的杭州经营路径包括合法租赁空间、停车与充电、社区服务运营、节能绩效等，逐项调查资产边界、经营方、收费方式、成本和市场需求。可经营空间不足而公共目标明确的方案，同样可以比较财政承受能力和年度维护支出。

## 6. 专家规则候选与杭州迁移清单

| 候选规则 | 触发数据 | 输出 |
|---|---|---|
| `SH-CAND-M01` 保护价值与结构修复可行性前置 | 保护名录、鉴定、修复方案、消防与日照 | 保留/局部更新/重建可行组合 |
| `SH-CAND-M02` 措施按楼栋和资产拆分 | 分栋工程现状、间距、基础、户型和功能缺口 | 混合方案、措施依赖与工程量 |
| `SH-CAND-E01` 资金与资产收入一一映射 | 可经营资产、权属、授权、市场、投入和维护 | 可核对现金流及资金缺口 |
| `SH-CAND-E02` 住户得益与支付能力联动 | 权利类型、住户需求、收入与分摊方案 | 分群支付安排和协商任务 |
| `SH-CAND-D01` 缺项按决策影响分级 | 经营权、结构、规划、关键成本或市场缺项 | 先补充关键资料再判断，或保留可独立推进措施 |

候选规则供导师审核后接入系统。上海案例中得到的是措施组合、协商方法和字段结构；杭州需要重新采集权利与审批条件、成本、租售市场、目标人群预算、入住率及维护合同，形成自己的方案比较。

补充阶段对照：杨浦区2026年4月资料记载凤南一村1813户、8栋20—26层、首栋封顶，配套公共服务设施超过6000平方米；作为在建阶段资料单独保存。[凤南一村施工节点](https://www.shyp.gov.cn/shypq/xwzx-jzdt/20260403/502950.html)
