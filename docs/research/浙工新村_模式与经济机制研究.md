# 浙工新村：模式组合、成本收益与决策研究

研究日期：2026年10月12日。案例位置：杭州拱墅区朝晖六区。

浙工新村已完成原址重建，本研究围绕它怎样组织改造、怎样筹资回收、怎样验证居民与市场接受度，形成可用于其他候选小区的对照案例。研究按措施拆分，市场、成本、权属与时间同时入表。

## 1. 案例拆分：一条主模式与五项措施

主模式为业主自主更新和危旧房原址重建，组合了户型/面积再配置、地下停车、公共服务嵌入及治理运营。它同时包含物理更新方式、资金组织方式和运营安排。新区域应按楼幢状况选择措施组合，可以保留一部分建筑，拆建另一部分，再配置公共或经营空间。

## 3. 造血机制与分账

建设资金账户记录居民出资、公共支持、车位与合法经营空间回收及融资。运营账户记录租赁、服务和停车经营实收、维护、税费与补贴。居民账户记录家庭追加支付、居住改善及资产变化。三个账户分别展示，方便回答“谁花钱、谁得到什么、什么时候回款”。

历史报价下，75平方米计价原面积、20平方米自选扩面、1个车位的算例为：75×1350＋20×34520＋221000＝101.265万元；不购车位为79.165万元。此为同档政策的操作情景，补助、装修、临时租房与融资另列。

2024年报道整体费用约5.3亿元、自筹约4.7亿元；2026年回顾报道分别约5.6亿元、4.9亿元，按版本保存。对应比例为88.7%和87.5%。最终分项决算及实收台账列入待采。

已公开的重建住宅总数仍为548套，原居民扩面形成改善及出资来源；地下车位存在购买价格记录；北侧商铺已出现，但本轮未获得商铺面积、经营权和租约。该案例的持续现金流模型先保留空字段，收到合同和台账后计算。

市场验证已有两类记录：2025年单套网签41114元/平方米，2026年报道概括成交超过4万元/平方米、交付后成交100多套。后续以同品质、同面积、同楼层和同时间成交配对，计算居民净资产变化；新增可变现项目资产根据批准面积去向另算。

### 3.1 谁付钱、谁收款、谁受益

|渠道|付款方|收款方/权利人|经济效果|待采字段|
|---|---|---|---|---|
|居民原面积与扩面出资|原产权家庭|建设结算主体|筹集建设资金，家庭取得新住房及自选面积|分户实收、结算合同、支付日期|
|政府支持|专项资金渠道|依项目分项拨付给主体或居民|支持基本公共改善与过渡安排|补贴名单、拨付及对应用途|

|商铺租赁|承租经营者|产权人或合法运营方|持续租赁与服务经营收入|面积、经营权、租约、空置率、税费|

浙工新村的主要建设资金机制是业主出资与公共支持，并由国企在建设期垫资；自住住房重建和面积优化带来居民端改善及资产价值变化。二手市场已出现产权人售出回款。车位回收和沿街商铺运营另有明确收款角色，后续以权属、收款和专项成本台账计算。它的价值可以在居民资产账户体现，企业端则按承包、代建、融资、合法资产销售与运营合同记录现金。

对应模型分别计算：

- 建设与运营净现金＝居民实收＋政府支持实收＋可售资产实收＋运营净现金－工程款－过渡费用－咨询迁改－税费－融资成本－承担的维护。
- 居民净资产变化＝更新后可实现住房价值－更新前同类住房价值－家庭净新增投入－交易与融资成本。
- 居民出售回款＝二手成交实收－交易税费－剩余贷款，另附此前资金投入记录。

居民目标群体以原产权业主自住和养老改善为主，市场群体是周边改善型买家；两者分别调查“愿意改什么”与“实际付得起多少”。家庭资金分布、融资条款、真实租约暂保留null，通过问卷、银行合同和租约补齐。

## 4. 模式判定与方案比较

建议建立五组候选组合：保留综合整治、加固与功能更新、局部拆建＋保留整治、整体自主拆建、居住更新＋经营服务空间。治理组织（业主自主/公共平台/市场协作）及资金包（自筹/补贴/合法资产回收/运营）分别配置。

第一轮核对安全、权籍、规划和有效居民决议；第二轮计算各组合的居民负担、建设资金闭合、阶段资金峰值、运行收支；第三轮比较公共服务、生活干扰、长期维护和市场需求。没有租金、权属或销售样本的收入项保留缺项，调查任务指向具体材料。
